## 一、现状

### 1.1 已有数据

| 数据       | 表                          | 用途                         |
| ---------- | --------------------------- | ---------------------------- |
| 资产账户   | `asset_account`             | 流动资产、投资资产、自用资产 |
| 负债账户   | `liability_account`         | 短期负债、长期负债           |
| 流水       | `ledger_transaction`        | 收入、支出、结余             |
| 预算       | `ledger_budget`             | 预算执行率                   |
| 净资产快照 | `ledger_net_asset_snapshot` | 净资产趋势                   |
| 用户画像   | `portal_user` + 扩展        | 年龄、行业、岗位、收入类型   |

### 1.2 已有能力

- 记账（六类型：支出/收入/转账/还款/借款/校准）
- 资产负债管理
- 报表中心（收支/资产负债）
- 预算管理
- AI 财务分析（已有基础）

### 1.3 缺口

| #    | 缺口                 | 影响                       |
| ---- | -------------------- | -------------------------- |
| G1   | 财务比率未系统化计算 | 只有原始数据，没有衍生指标 |
| G2   | 无财务健康评分       | 用户不知道自己的财务水平   |
| G3   | 无兜底分析           | AI 不可用时，页面空白      |
| G4   | AI 上下文不完整      | 未传用户画像，分析不个性化 |
| G5   | 报表展示不聚焦       | 信息多但重点不突出         |

### 3.5 比率计算（确定性）

```java
public RatiosVO calcRatios(FinancialReportVO vo) {
    RatiosVO r = new RatiosVO();
    BigDecimal totalAssets = vo.getBalanceSheet().getTotalAssets();
    BigDecimal totalLiabilities = vo.getBalanceSheet().getTotalLiabilities();
    BigDecimal currentAssets = vo.getBalanceSheet().getCurrentAssets();
    BigDecimal totalIncome = vo.getIncomeStatement().getTotalIncome();
    BigDecimal totalExpense = vo.getIncomeStatement().getTotalExpense();
    BigDecimal passiveIncome = vo.getIncomeStatement().getPassiveIncome();
    BigDecimal investmentAssets = vo.getBalanceSheet().getInvestmentAssets();

    // 1. 资产负债率
    r.setDebtToAsset(divide(totalLiabilities, totalAssets));
    // 2. 紧急预备金月数
    r.setEmergencyFundMonths(divide(currentAssets, monthlyExpense(vo)));
    // 3. 结余率
    r.setSurplusRatio(divide(totalIncome.subtract(totalExpense), totalIncome));
    // 4. 负债收入比
    r.setDebtToIncome(divide(monthlyDebtPayment(vo), totalIncome));
    // 5. 被动收入占比
    r.setPassiveIncomeRatio(divide(passiveIncome, totalIncome));
    // 6. 投资资产占比
    r.setInvestmentAssetRatio(divide(investmentAssets, totalAssets));

    return r;
}
```

## 四、规则引擎（兜底核心）

### 4.1 评分卡

| 指标           | 权重 | A（满分） | B（良好） | C（预警） |
| -------------- | ---- | --------- | --------- | --------- |
| 资产负债率     | 30   | < 50%     | 50%-70%   | > 70%     |
| 紧急预备金月数 | 25   | ≥ 6 月    | 3-6 月    | < 3 月    |
| 结余率         | 20   | ≥ 30%     | 10%-30%   | < 10%     |
| 负债收入比     | 15   | < 30%     | 30%-50%   | > 50%     |
| 被动收入占比   | 10   | ≥ 20%     | 10%-20%   | < 10%     |

### 4.2 评分逻辑

```java
public ScoreVO calcScore(RatiosVO r) {
    int score = 0;
    score += scoreDebtToAsset(r.getDebtToAsset()) * 30;
    score += scoreEmergencyFund(r.getEmergencyFundMonths()) * 25;
    score += scoreSurplus(r.getSurplusRatio()) * 20;
    score += scoreDebtToIncome(r.getDebtToIncome()) * 15;
    score += scorePassiveIncome(r.getPassiveIncomeRatio()) * 10;

    ScoreVO vo = new ScoreVO();
    vo.setTotal(score);
    vo.setGrade(gradeOf(score));
    vo.setDetail(buildDetail(r));
    return vo;
}

private String gradeOf(int score) {
    if (score >= 85) return "A";
    if (score >= 70) return "B";
    if (score >= 60) return "C";
    return "D";
}
```

### 4.3 兜底文案

| 等级       | 文案                                                         |
| ---------- | ------------------------------------------------------------ |
| A（≥85）   | 财务状况优秀，资产负债结构合理，流动性充足，建议适度投资。   |
| B（70-84） | 财务状况良好，结余能力较强，但流动性略显不足，建议补充应急储备。 |
| C（60-69） | 财务状况一般，存在一定风险，建议优先偿债并控制支出。         |
| D（<60）   | 财务状况预警，负债过高或流动性严重不足，建议立即制定改善计划。 |

## 五、AI 增强

### 5.1 触发时机

- 用户主动点击"AI 分析"
- 或异步任务自动生成（可选）

### 5.2 上下文组装

```json
{
  "period": "2026-09",
  "profile": {
    "age": 31, "industry": "IT", "position": "Java工程师",
    "marital_status": "single", "has_mortgage": true,
    "has_side_income": true, "income_types": ["salary", "investment"]
  },
  "balance_sheet": { "..." },
  "income_statement": { "..." },
  "ratios": { "..." },
  "score": { "total": 80, "grade": "B" }
}
```

### 5.3 提示词模板

```
你是财务分析师。基于以下数据，给出财务健康分析。

用户画像：{profile}
财务报表：{balance_sheet} / {income_statement}
关键比率：{ratios}
规则评分：{score}

请输出：
1. 整体评价（结合年龄/行业）
2. 优势（2-3 条）
3. 风险点（2-3 条）
4. 建议（3 条，含创业/投资/风险）

要求：基于数据不编造，建议具体可执行，每段不超过 3 句。
```

### 5.4 兜底策略

```
AI 可用 → 展示个性化分析
AI 不可用 → 展示规则引擎的等级文案
```
