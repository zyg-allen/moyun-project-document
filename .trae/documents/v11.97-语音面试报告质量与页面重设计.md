# v11.97 语音面试报告质量与页面重设计

## Context

用户实测报告（id=17）质量极差：所有题 50 分、亮点"暂无亮点数据"、改进建议复述问题原文、技能标签显示原始 JSON（`"Java": {"level":"了解"}`）、岗位匹配度=总分、文案模板化。根因调研确认：

1. **逐题 LLM 分析失败→兜底 50 分**：`runBatchAnalysis` → `analyzeAnswerByLlm` 走 `aiSceneJsonClient`（场景网关）失败返回 null → 兜底默认 50 分（V3 规则引擎已删）。而**面试主对话走 `agentClient.chatStream`（agent48 直连）实测可用**——网关通道失败、直连通道可用。
2. 文案模板化：`buildSummary`（L1931）/`buildSuggestion`（L1940）/`buildImprovementSuggestions`（L1610）硬编码拼接。
3. `buildCandidateProfile`（L1326）skills 直接塞原始 JSON；`buildJobInfo`（L1385）matchRate=totalScore 硬套。
4. `knowledgePoints`（题库 tags 聚合）用户明确要求删除。
5. 后端报告级维度聚合用旧 key `coverage/length/structure`，与逐题六维 `relevance/professionalism/fluency/interactivity/confidence/logic` 不一致。

目标：报告基于**简历+岗位+对话内容**产出有水平的评分、评价、建议；删除关联题库；重设计报告页排版样式；存量报告可重新生成（id=17 立即受益）。

## 后端改造（3 文件）

```java
private String overallComment;          // 整场总评 3-5 句（旧报告 null → 前端回退 summary）
```

`QuestionReview` 补 `userAnswer`、`qaId` 两字段（前端类型已有、后端未输出）。

### 2. VoiceInterviewServiceImpl.java（核心）

**(1) 整场 LLM 复盘 `enhanceReportByAgent`（~150 行，纯增量分支）**
- 调用点：`aggregateAndStoreReport` 中 `fresh.setReport(toJson(report))` 之前；调用前 `updateAnalysisProgress(interviewId, 85)`
- 通道：`agentClient.resolveAgent(interview.getAgentId())` → `agentClient.chat(agent, messages)`（与主对话同链路，已验证可用）；agent 为 null 直接 return 保留兜底
- 输入：岗位+JD（`readInterviewConfig`）+ 简历摘要 + 全部问答对 + 兜底分；**不注入 agent.systemPrompt**（报告分析是代码级任务）
- 输出 JSON（prompt 约束：highlights/weakPoints 各 2-4 条、suggestions 3-5 条每条≤60字、comment≤80字）：
  ```json
  { "overallComment": "...", "jobMatch": {"rate": 78, "reason": "..."},
    "highlights": [{"title":"...","detail":"引用作答原话"}],
    "weakPoints": [{"title":"...","detail":"具体不足"}],
    "suggestions": ["..."], "perQuestion": [{"questionIdx":1,"score":72,"comment":"..."}],
    "dimensions": {"relevance":0,"professionalism":0,"fluency":0,"interactivity":0,"confidence":0,"logic":0} }
  ```
- 映射：overallComment/jobMatch（同步写 `jobInfo.matchRate`）/highlightViews+highlights 双写/weakPointViews+weakPoints 双写/suggestions 覆盖 improvementSuggestions/perQuestion 按 questionIdx 覆盖 reviews 的 score/feedback 并回写 QA 表/dimensions 六维 clamp
- 新增私有 `extractJsonObject(String raw)`：剥 ```json 围栏容错解析（AbstractAiSceneHandler L296-328 逻辑为 private 不可复用，类内重写）；解析失败追加约束重试一次，再失败 return 兜底
- 开头加 sys_config 开关检查 `voice.interview.reportLlm.enabled`（缺省 true，热回退用）

**(2) `formatSkills`**：解析 skills JSON → `"Java·了解 / Python·了解"`；解析失败原样返回。`buildCandidateProfile` 接入。

**(3) 维度 key 对齐**：`dimSums` 初始化（L1166-1168）改六维 key，修复报告级维度断链。

**(4) 删 knowledgePoints**：移除 L1295 调用 + 删 `buildKnowledgePoints/tryRagKnowledgePoints/tryLlmKnowledgeDesc` 三方法（`ragRetrievalService` 注入若无他引用一并移除，编译器验证）；VO 字段保留（旧数据反序列化兼容）。

**(5) QuestionReview 增强**（L1190-1195）：补 `setUserAnswer(qa.getUserAnswer())`、`setQaId(qa.getId())`。

**(6) `regenerateReport`（重置状态复用异步链路）**，踩坑点已确认：
- 主表重置：`analysisStatus=1、analysisProgress=0、report=null、summary=null`（**必须清 report**：L1153 报告非空时仅推进进度直接 return）
- QA 重置：已作答题 `analysisStatus=null、scoreDraft=null`（不清 scoreDraft 会二次融合失真；runBatchAnalysis 只处理 analysisStatus!=2 的题）
- `RUNNING_ANALYSIS.contains` 时抛"报告正在生成中"；非 finished 抛错
- `@Transactional` + `triggerBatchAnalysis`（自动走 afterCommit）
- 接口声明加入 `IVoiceInterviewService`

### 5. VoiceInterviewPage.vue（报告页重构，Step1-7 顺序执行）

1. **删 Tab**：「相关知识点」「面试官剖析」按钮与 content 块；`reportTab` 收窄为 `'summary' | 'dialog' | 'analysis'`
2. **迁移**：introScoreView 卡、改进建议列表、「按建议优化简历」按钮并入 summary tab
3. **新增头部横幅卡**（进度条与 profile-grid 之间）：综合得分+等级徽章+overallComment（回退 summary）+岗位匹配度（进度条+色阶+reason 一行）
4. **总览 Tab 重排**：左=六维雷达（填充色随分数色阶）+总分盒；中=AI 深度复盘+改进建议；右=亮点卡+薄弱弱点卡（`highlightItems` computed：highlightViews 优先回退 highlights，`pointDetail` 取 detail/quote）
5. **问题分析 Tab**：userAnswer 折叠展开（默认 2 行 line-clamp+展开按钮，不再 truncate 80）；分数色阶贯穿（>=80 绿/60-79 橙/<60 红）
6. **重新生成按钮**：report-actions 区加「🔄 重新生成报告」→ confirm → `regenerateVoiceReport` → `report.value=null; analysisState={active:true,progress:5}; startAnalysisPolling()`（复用现有轮询链路，analysisStatus=2 自动拉新报告）
7. **candidateSkills 防御**：raw 以 `{`/`[` 开头时前端 JSON.parse 再拼接（兜底存量数据）

### 6. MyVoiceInterviewsPage.vue

记录卡加「🔄 重新生成」入口：跳转 `/interview/voice?id={id}&regenerate=1`；VoiceInterviewPage onMounted 检测参数，报告加载完成后自动触发重新生成（不在列表页重复实现轮询）。
