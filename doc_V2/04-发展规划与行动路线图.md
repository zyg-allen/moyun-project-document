## 一、战略定位

### 1.1 核心定位

**墨韵·智库 = AI 时代的真人原创知识社区**

> 在 AI 内容泛滥的时代，我们相信真人的力量。墨韵·智库是一个让真人创作者分享散文、读书笔记、面试经验和技术洞察的社区。每一篇文章都来自真实的生活体验，每一次互动都有温度。

### 1.2 差异化竞争力

| 维度 | 墨韵·智库 | 竞品（简书/知乎/掘金） |
|---|---|---|
| 内容来源 | 真人原创，AI 辅助 | AI 与真人混杂 |
| 模块融合 | 散文+读书+面试+技术四合一 | 单一模块 |
| 社区调性 | 精品垂直 | 大众化/泛化 |
| 变现路径 | 内容价值直接变现（打赏/付费） | 流量+广告 |
| 信任体系 | 真人认证+原创标识+内容审核 | 弱/缺失 |

### 1.3 战略原则

1. **人本位**：真人创作为核心，AI 仅作辅助工具
2. **垂直化**：四模块各自深耕，不做大众化内容分发
3. **合规先行**：合规是护城河，不是成本
4. **质量优先**：宁可少而精，不要多而杂
5. **社区化**：用成长体系/Feed 流/社交互动建立社区氛围

## 二、分阶段发展路线图

### 2.1 阶段一：合规与工程化（当前 - 1 个月）

**目标**：完成上线前的合规整改和工程化基础

#### P0 任务（发版前必须完成）

| 任务 | 描述 | 预计工期 |
|---|---|---|
| ICP 备案 | 提交备案申请（如用内地服务器） | 7-20 工作日 |
| 隐私政策 | 起草 + 上线页面 + 注册勾选同意 | 3 天 |
| 内容审核 | 接入阿里云内容安全 + 自建敏感词库 | 5 天 |
| 实名认证 | 接入短信验证码 SDK | 3 天 |
| 账号注销 | 实现注销接口 + 30 天反悔期 | 3 天 |
| 未成年人保护 | 注册增加年龄确认 + 明确 18+ 定位 | 1 天 |
| 存量密码迁移 | 强制改密或批量 BCrypt | 2 天 |
| 读书模块 ISBN | 新增书籍来源字段 + 授权证明 | 2 天 |
| Docker 化 | Dockerfile + docker-compose | 3 天 |
| CI/CD | GitHub Actions / GitLab CI | 3 天 |

#### P1 任务（上线后 1 个月内）

| 任务 | 描述 |
|---|---|
| 用户协议完善 | 替换模板占位 |

**关键原则**：内容价值直接变现 > 流量广告变现
