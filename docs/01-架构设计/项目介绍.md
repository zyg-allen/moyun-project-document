## 一、项目定位

**旭林知行**（Xulin Zhixing）是一个 **AI 驱动的求职面试与学习成长平台**：以用户个人视角记录成长履历——学习、刷题、面试、阅读、写作整合为一条成长时间线，并延伸至个人财务管理（记账 App），用 AI 赋能帮助用户"变成一个更好的人"。

### 品牌口号

> 知行合一，助你上岸

### 核心差异化

1. **AI 语音面试官**（旗舰拉新引擎）：真实语音对话面试（ASR 实时转写 + TTS 流式播报 + Agent 自由面试滑窗记忆），基于简历+JD+对话的整场 LLM 复盘报告，历史面试完整留存可重新生成
2. **AI 统一网关**（技术底座）：全量 LLM 调用场景化收口（配置即治理：限流/熔断/注入防护/执行日志/热开关）
3. **个人记账 App**（第四端）：uni-app 三端，资产负债/报表/预算 + AI 财务分析
4. **OJ 在线判题**：Docker 沙箱 + 异步队列，对标力扣/牛客
5. **成长时间线**（情感锚点）：所有行为统一追踪，进步可视化回溯

### 目标用户

- **求职者**：AI 语音面试 + 简历深度优化 + 题库刷题 + 面经复盘
- **学习者**：刷题日历、知识图谱、错题本
- **内容创作者**：文章/专栏，打赏、付费阅读、VIP 订阅变现
- **大众用户**：个人记账（App）、读书空间（版权后期处理）

## 四、核心特性

- **双用户体系**：sys 管理员与 portal 用户双 FilterChain 独立认证；私信跨体系
- **配置三层**：环境变量（密钥）→ yaml（结构化）→ sys_config（运行时热生效）
- **OJ 判题**：Docker 沙箱（CPU/内存/PID/网络隔离）+ Redis 异步队列，多语言
- **金额铁律**：全链路 RMB 元（DECIMAL(18,2)/BigDecimal），禁用分与浮点
- **安全**：XSS 过滤/敏感词/限流/防重复提交/证件银行卡 AES-GCM 加密/实名合规

## 六、快速开始

```bash
# 环境：JDK 21+ / Node 18+ / MySQL 8.0+ / Redis 6.0+ / Maven 3.8+
# 1. 初始化数据库（DDL → DML 4 分片 → 日期序增量补丁）
cd moyun-server/src/main/resources/sql
mysql -u root -p moyun-db < moyun-db-ddl.sql
mysql -u root -p moyun-db < 202608201435-moyun-db-dml-1.sql   # 至 -4
# 2. 后端
cd ../../../.. && export TOKEN_SECRET="your-secret-64-chars" && mvn spring-boot:run
# 3. 前端三端
cd ../moyun-portal && pnpm install && pnpm run dev
cd ../moyun-admin-vue && pnpm install && pnpm run dev
cd ../moyun-ledger-app && npm install && npm run dev:h5
```

详见 [开发指南](../02-开发指南/开发指南.md) 和 [部署指南](../03-部署运维/部署指南.md)。
