# 墨韵·智库 项目介绍

> 版本：v5.2 | 更新日期：2026-07-19 | 状态：活跃开发中

## 一、项目定位

**墨韵·智库**（Moyun）是一个面向内容创作者、求职者、读书爱好者、学习者的**综合性内容与学习社区平台**，定位为「文学×技术」双内容垂类社区 + 知识工具站 + 创作者经济三合一平台。

### 品牌口号
> 在浮躁的世界，留一页纸给灵魂

### 目标用户
- **内容创作者**：在文章、专栏、征文活动中发表作品，通过打赏、付费阅读、创作者分成获得收益
- **求职者**：通过面试题库、面经、简历工具、AI 模拟面试官提升求职能力
- **读书爱好者**：在读书空间阅读连载书籍、管理书架、摘录金句
- **学习者**：使用学习计划、错题本、在线代码运行、PK 对战等工具持续学习

## 二、技术栈

### 后端（moyun-server）
- **核心**：Spring Boot 3.3.2 + Java 21 + Spring Security 6.3.1 + JJWT 0.12.3
- **持久层**：MyBatis-Plus 3.5.7 + Druid 1.2.23（多数据源）
- **工作流**：Flowable 7.1.0（BPMN 2.0）
- **AI 能力**：LangChain4j 1.12.2 + 通义大模型（DashScope）
- **存储**：MySQL 8.0 + Redis 6.0 + MongoDB + MinIO
- **任务调度**：Quartz
- **API 文档**：Knife4j 4.4.0（OpenAPI 3）
- **工具**：Hutool 5.8.44、Apache POI 5.2.5、PDFBox 3.0.3、Aviator 5.3.3、Velocity 2.3

### 前端门户（moyun-portal）
- Vue 3.4 + Vite 5 + TypeScript 5.3 + Pinia 3 + Vue Router 4
- Tailwind CSS + lucide-vue-next + @vueuse/head（SEO）
- marked + highlight.js（Markdown）+ @vueup/vue-quill（富文本）
- Dayjs + Zod

### 前端后台（moyun-admin-vue）
- 基于 RuoYi-Vue 3.8.7 二次开发
- Vue 3.4 + Element Plus 2.4.3 + Vite 5
- bpmn-js 11.1（BPMN 流程设计器）+ @highlightjs/vue-plugin
- axios 0.27.2 + @vueuse/core

## 五、核心特性

### 5.1 双用户体系
- **sys 用户**：后台管理员，走 `/login` 接口，JWT 由 `TokenService` 签发
- **portal 用户**：前台用户，走 `/portal/login` 接口，JWT 由 `PortalTokenService` 签发
- 两套独立的 Spring Security FilterChain、独立的密码加密、独立的权限体系
- 私信系统支持跨用户体系（portal 用户 ↔ sys 管理员）

### 5.2 成长体系闭环
- `portal_user_growth` 记录成长值/积分/等级/连续签到/补签卡
- `IPortalGrowthService.recordEventWithTarget()` 统一埋点入口
- 规则未配置时安全返回 0，不抛异常
- 等级阈值：`{0, 100, 300, 700, 1500, 3000, 6000, 10000, 20000}`

### 5.3 积分打赏 MVP
- 用 `portal_user_growth.points`（积分账户）替代真实资金
- 打赏方扣积分、被打赏者得积分，绕开支付资质门槛
- 原子扣积分 SQL：`UPDATE ... SET points = points - #{delta} WHERE user_id = #{userId} AND points >= #{delta}`
- `article_paid`（付费阅读）走占位逻辑，待支付通道接入

### 5.4 AI 能力集成
- LangChain4j + 通义大模型（DashScope）
- AI 模拟面试官：根据岗位和简历生成面试题，实时对话
- 创作者中心：AI 辅助内容生成

### 5.5 Flowable 工作流
- 后台审批流（文章审核、创作者认证）
- BPMN 2.0 可视化流程设计器（bpmn-js）
- 流程定义/实例/任务/表单/表达式/监听器全套

### 5.6 多类型存储
- MySQL：业务数据（169 张表）
- MongoDB：文档存储（如 AI 对话记录）
- Redis：缓存/会话/限流/验证码/字典缓存
- MinIO：对象存储（文件/图片）

### 5.7 SEO 与内容安全
- 每页 `useHead(generateSeo)` 注入 SEO 元信息
- `sanitizeHTML` 过滤 MarkdownRenderer 的 XSS
- 文件上传白名单（19 扩展名）
- SSRF 防护（拦截内网 IP）

## 八、快速开始

### 环境要求
- JDK 21+
- Node.js 18+
- MySQL 8.0+
- Redis 6.0+
- Maven 3.8+
- MinIO（可选，文件存储）

### 后端启动
```bash
cd moyun-server
# 配置环境变量（至少 TOKEN_SECRET，64+ 字符）
export TOKEN_SECRET="your-secret-key-at-least-64-characters-long-xxxxxxxxxxxxx"
# 初始化数据库
mysql -u root -p < src/main/resources/sql-organized/01_system/01_system_tables.sql
# ... 按顺序执行其他 SQL（见 sql-organized/README.md）
mvn spring-boot:run
```

### 前端门户启动
```bash
cd moyun-portal
npm install
npm run dev
```

### 前端后台启动
```bash
cd moyun-admin-vue
npm install
npm run dev
```

详见 [03_开发指南.md](file:///workspace/moyun-project-document/docs/03_开发指南.md) 和 [04_部署指南.md](file:///workspace/moyun-project-document/docs/04_部署指南.md)。
