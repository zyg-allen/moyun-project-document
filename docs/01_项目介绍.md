## 一、项目定位

**墨韵·智库**（Moyun）是一个 **AI 驱动的个人成长平台**，核心理念是以用户个人视角记录成长履历——将学习、刷题、面试、阅读、写作整合为一条成长时间线，利用 AI 赋能帮助用户"变成一个更好的人"。

### 品牌口号

> 让成长有迹可循

### 核心差异化

不做"每一个模块都做到极致"的综合平台（竞争者太多），而是做**一条以面试成长为切入点的个人成长时间线**：

1. **AI 模拟面试**为核心拉新引擎——真实对话场景，AI 智能评分，弱项分析
2. **OJ 在线判题**为技术壁垒——Docker 沙箱 + 异步队列，对标力扣/牛客
3. **成长时间线**为情感锚点——所有行为统一追踪，进步可视化回溯

### 目标用户

- **求职者**：通过 AI 模拟面试 + 题库刷题 + 面经复盘提升面试能力
- **学习者**：使用刷题日历、知识图谱、错题本持续学习
- **内容创作者**：发表文章/专栏，通过打赏、付费阅读获得收益
- **读书爱好者**：阅读公开书籍、管理书架、摘录金句（版权风险已知，后期处理）

## 五、核心特性

### 5.1 双用户体系

- **sys 用户**：后台管理员，`/login` 接口，`TokenService` 签发 JWT
- **portal 用户**：前台用户，`/portal/login` 接口，`PortalTokenService` 签发 JWT
- 两套独立的 Spring Security FilterChain、独立密码加密、独立权限体系
- 私信系统支持跨用户体系

### 5.2 认证分级（v9.0 更新）

| 操作 | 认证要求 |
|------|----------|
| 话题发布 | 仅需登录（v9.0 从创作者认证降级） |
| 文章发布 | 需创作者认证 |
| 专栏创建 | 需创作者认证 |
| 面试经验发布 | 需创作者认证 |
| 评论/点赞 | 仅需登录 |

### 5.3 OJ 判题系统

- Docker 沙箱隔离：CPU/内存/PID限制 + 网络隔离 + 只读文件系统
- 异步判题队列：Redis List + Worker 线程池
- 多语言支持：Java/Python/C++/JavaScript/Go
- 判题结果：AC/WA/TLE/MLE/RE/CE + 运行时间 + 内存

### 5.4 AI 模拟面试

- 基于 LangChain4j + 通义大模型
- 多轮对话式面试，根据岗位和简历动态出题
- AI 智能评分与弱项分析
- WebSocket 实时对话

### 5.5 成长体系闭环

- `recordEventWithTarget()` 统一事件追踪入口
- 所有模块（文章/话题/面试/学习/阅读）共享成长事件
- 规则可后台配置（growth-config 5 Tab：规则+成就+徽章+日志+用户）
- 时间线可视化展示用户成长轨迹

### 5.6 首页双态设计（v9.0 改版）

- **游客态**：平台价值展示（3卡片）+ AI面试CTA + 平台数据
- **登录态**：成长仪表盘（4指标：今日刷题/面试均分/阅读进度/成长等级）+ 继续学习CTA
- 5屏布局：Hero → 面试+学习 → 读书+文章+话题 → 成长时间线 → 社区动态+标签

## 八、快速开始

### 环境要求

- JDK 21+
- Node.js 18+
- MySQL 8.0+
- Redis 6.0+
- Maven 3.8+
- Docker 20+（OJ判题需要）

### 后端启动

```bash
cd moyun-server
export TOKEN_SECRET="your-secret-key-at-least-64-characters-long"
# 初始化数据库
mysql -u root -p < src/main/resources/sql/init_v7.8.sql
# 执行v9.0升级脚本
mysql -u root -p < src/main/resources/sql/upgrade_v9.0_admin_refactor.sql
mvn spring-boot:run
```

### 前端启动

```bash
# 门户
cd moyun-portal && pnpm install && pnpm run dev

# 后台
cd moyun-admin-vue && pnpm install && pnpm run dev
```

详见 [03_开发指南.md](03_开发指南.md) 和 [04_部署指南.md](04_部署指南.md)。
