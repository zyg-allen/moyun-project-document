# UI 设计 Token 规范（V1.0）

> 目的：页面不再各写各的字号/间距/圆角，统一走主题变量与 Token。
> 现状：主题色与文字色已变量化；字号/间距/圆角仍分散，本文定义基线。

---

## 一、颜色（已有，禁止硬编码）

| Token | 用途 |
|---|---|
| `--bg` / `--surface` | 页面背景 / 次级背景 |
| `--card` | 卡片背景 |
| `--text-main` / `--text-sub` / `--text-muted` | 主/次/弱文字 |
| `--primary` / `--primary-soft` / `--primary-text` | 主色/浅底/其上文字 |
| `--income` / `--expense` / `--warning` | 语义色 |

规则：

- 文字颜色只用以上变量；
- 彩色背景上的文字用 `--primary-text` 或 `--on-primary`；
- 禁止写死 `#fff`（除纯色主按钮文字）。

## 二、字号

| 级别 | 大小 | 用途 |
|---|---|---|
| 特大 | 40~46rpx | 首页大数字 |
| 标题 | 30~34rpx | 页面/卡片标题 |
| 正文 | 26~28rpx | 列表主文案 |
| 辅助 | 22~24rpx | 标签、说明 |
| 最小 | 18~20rpx | 时间、角标（不再更小） |

> 当前最小 16rpx 仅存在于存钱宫格日期，建议不低于 18rpx。

## 三、间距

| Token | 值 | 用途 |
|---|---|---|
| `space-xs` | 8rpx | 图标与文字 |
| `space-sm` | 16rpx | 行内元素 |
| `space-md` | 24rpx | 卡片外边距、行间距 |
| `space-lg` | 32rpx | 卡片内边距 |
| `space-xl` | 48rpx | 区块之间 |

## 四、圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 12rpx | 标签、输入框 |
| `radius-md` | 16~20rpx | 卡片 |
| `radius-lg` | 24rpx | 弹层 |
| `radius-pill` | 999rpx | 按钮、胶囊 |

## 五、状态组件

- 列表统一：`SkeletonList`（加载）→ 空态 → 失败重试；
- 表单统一：`FieldError` 行内红字，不再只弹 toast；
- 弹层 z-index 统一 `2000`，必须高于 TabBar（998）。

## 六、落地检查

- [ ] 新增页面不出现硬编码颜色
- [ ] 字号不小于 18rpx
- [ ] 卡片圆角/间距取自 Token
- [ ] 列表有加载/空/失败三态
- [ ] 表单错误用 `FieldError`
