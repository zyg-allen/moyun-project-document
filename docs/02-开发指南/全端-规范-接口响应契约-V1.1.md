# 接口响应与分页契约（V1.1）

> 文档版本：V1.1 · 2026-10-28（新增存钱 VO/`bizType` 约定）
> 目的：终结"有的接口返数组、有的返 `{records,total}`、有的返 `{plans}`"，避免前端假空态。
> 状态：规范先行，按模块渐进迁移；新接口必须遵守，旧接口逐步对齐。

---

## 1. 统一响应结构

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

| 字段 | 说明 |
|---|---|
| `code` | 200=成功；其余为业务错误码（见第 4 节） |
| `msg` | 用户可读提示；成功固定 `success` |
| `data` | 业务数据；无数据时为 `null` 或 `{}`，**不要省略** |

## 2. 列表与分页

### 2.1 分页列表（统一）

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "records": [],
    "total": 0,
    "pageNum": 1,
    "pageSize": 20
  }
}
```

- `records` 必须是数组；
- `total` 为总数；
- 排序、筛选参数放 query，不改变返回结构。

### 2.2 不分页列表

```json
{ "code": 200, "msg": "success", "data": { "records": [] } }
```

也允许 `data` 直接为数组，但**同一模块内必须统一**。

### 2.3 详情

```json
{ "code": 200, "msg": "success", "data": { "id": 1 } }
```

禁止把 Entity 直接塞进 `data`，必须用 VO，只暴露需要的字段。

## 3. 错误与状态码

| code | 含义 | HTTP |
|---|---|---|
| 200 | 成功 | 200 |
| 400 | 参数错误 | 200（历史约定）或 400 |
| 401 | 未登录/令牌过期 | 200（前端按 body 处理） |
| 403 | 无权限/未授权数据 | 200 |
| 404 | 资源不存在 | 200 |
| 429 | 触发限流 | 429 |
| 500 | 服务异常 | 500 |

> 迁移期允许 HTTP 200 + body code；**网关告警请单独看 code 字段**。新接口建议 401/403 用真实 HTTP 状态码。

## 4. 前端解析规范

统一使用 `src/utils/response.js`：

```js
import { listOf, totalOf } from '@/utils/response';

const data = await listApi();
const rows = listOf(data);      // 兼容数组 / records / rows / list / plans
const total = totalOf(data, rows.length);
```

禁止在页面里写 `data.records || data.rows || []` 这类散落判断。

## 5. 迁移步骤（按模块）

1. 选一个模块（建议存钱/资产）；
2. 后端 Controller 统一返回 `AjaxResult.success(data)`，分页用 `Page` → `{records,total,pageNum,pageSize}`；
3. 前端该模块全部改用 `listOf/totalOf`；
4. 加一条**契约测试**：断言 `data.records` 为数组、`total` 为数字；
5. 模块验收后，再迁下一个。

## 7. 记账/存钱 VO 约定

### 7.1 存钱详情

```json
{
  "plan": { "id": 1, "name": "52周存钱", "method": "52week", "targetAmount": 13780.00, "currentAmount": 30.00, "status": 1 },
  "records": [
    { "id": 10, "periodIndex": 1, "targetAmount": 10.00, "amount": 10.00, "status": 1, "recordDate": "2026-10-26", "transactionId": 900 }
  ]
}
```

- `records` 必须按 `periodIndex` 升序；
- `status`：0 待存、1 已存、2 未完成；
- `transactionId` 可空。

### 7.2 流水列表

- 每条记录含 `bizType`；存钱转入 `bizType=saving`；
- 前端展示优先级：`description` > 类型文案；`bizType=saving` 时类型显示「存钱转入」。
