## 四、OJ 判题架构

### 4.1 判题流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant API as JudgeController
    participant Q as Redis队列
    participant W as JudgeWorker
    participant D as Docker沙箱
    participant DB as MySQL
    
    U->>API: 提交代码
    API->>DB: 保存提交记录(status=PENDING)
    API->>Q: 推送到判题队列
    API-->>U: 返回submissionId
    
    W->>Q: 消费队列消息
    W->>DB: 获取题目+测试用例
    W->>D: 创建容器（CPU/内存/PID限制）
    D->>D: 编译代码
    D->>D: 逐个运行测试用例
    D-->>W: 返回运行结果(时间/内存/输出)
    W->>W: 对比输出与期望
    W->>DB: 更新提交状态(AC/WA/TLE/MLE/RE/CE)
    W->>D: 清理容器
```

### 4.2 安全隔离

| 维度 | 限制 |
|------|------|
| CPU | `--cpus=1` |
| 内存 | `--memory=256m` |
| 进程数 | `--pids-limit=50` |
| 网络 | `--network=none` |
| 文件系统 | 只读根 + 临时tmpfs |
| 超时 | 可配置（默认5秒） |

## 五、AI 模块架构

### 5.1 模块组成

| 子模块 | 说明 | 技术 |
|--------|------|------|
| AI 模拟面试 | 多轮对话面试 + 智能评分 | LangChain4j + 通义大模型 + WebSocket |
| 知识库 RAG | 文档导入 + 向量化 + 语义搜索 | LangChain4j Embedding + 向量库 |
| 图表分析 | 自然语言生成图表 | LLM + ECharts配置生成 |
| SQL 问答 | 自然语言查询数据库 | LLM + SQL生成 + 结果可视化 |
| 工作流 | 可视化AI工作流编排 | 自研DAG执行引擎 |
| Agent | 自主任务执行 | LangChain4j Agent + 工具调用 |

### 5.2 面试AI流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant WS as WebSocket
    participant S as InterviewService
    participant LLM as 通义大模型
    participant DB as MySQL
    
    U->>WS: 建立连接（面试ID+岗位+简历）
    WS->>S: 开始面试
    S->>LLM: 系统Prompt（面试官角色+岗位要求）
    LLM-->>S: 首个问题
    S-->>U: 推送问题
    
    loop 多轮对话
        U->>WS: 回答
        WS->>S: 转发回答
        S->>LLM: 上下文+用户回答
        LLM-->>S: 追问/评价/下一题
        S-->>U: 推送回复
    end
    
    U->>WS: 结束面试
    S->>LLM: 生成面试报告（评分+弱项+建议）
    LLM-->>S: 报告
    S->>DB: 保存面试记录+报告
    S-->>U: 推送面试报告
```

## 六、成长系统架构

### 6.1 统一事件追踪

```
recordEventWithTarget(userId, eventType, targetId, targetType, metadata)
    │
    ├── 写入 portal_growth_log（成长日志）
    ├── 查询 portal_growth_rule（成长规则）
    ├── 计算积分/经验值增量
    ├── 更新 portal_user_growth（用户成长数据）
    ├── 检查徽章/成就解锁条件
    └── 触发通知
```

### 6.2 事件类型

| 事件类型 | 触发模块 | 积分/经验 |
|----------|----------|-----------|
| ARTICLE_PUBLISH | 文章 | +50 |
| ARTICLE_LIKED | 文章 | +5 |
| TOPIC_CREATE | 话题 | +10 |
| INTERVIEW_COMPLETE | 面试 | +30 |
| QUESTION_SOLVED | 学习/OJ | +20 |
| READING_CHAPTER | 读书 | +5 |
| DAILY_SIGN_IN | 签到 | +1~10 |
| ... | ... | 后台可配置 |

### 6.3 后台管理（growth-config 5 Tab）

| Tab | 说明 |
|-----|------|
| 规则 | 成长规则CRUD（事件类型→积分/经验映射） |
| 成就 | 成就定义与解锁条件 |
| 徽章 | 徽章图标与展示 |
| 日志 | 成长日志查询 |
| 用户 | 用户成长数据查询 |
