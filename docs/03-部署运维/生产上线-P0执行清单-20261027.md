# 生产上线 P0 执行清单（2026-10-27）

> 代码侧已就绪：health 公开、限流/防重 96%+、上传白名单、traceId、接口统计。
> 本文是**部署机上的操作清单**，按顺序执行即可。

## 1. MinIO

```bash
export MINIO_ROOT_PASSWORD='强随机密码'
export MINIO_DATA_DIR=/data/minio
bash deploy/start-minio.sh
```

验证：

```bash
curl -sf http://127.0.0.1:9000/minio/health/live && echo OK
mc ls local/moyun
```

写入 `prod.env`：

```
MINIO_ENDPOINT=http://127.0.0.1:9000
MINIO_ACCESS_KEY=<root user>
MINIO_SECRET_KEY=<root password>
MINIO_BUCKET_NAME=moyun
MINIO_ACCESS_URL=https://oss.<你的域名>
```

> 不要把 9000/9001 直接暴露公网；控制台仅内网/跳板机访问。

## 2. Nginx + HTTPS

```bash
sudo cp deploy/nginx.conf.example /etc/nginx/conf.d/moyun.conf
# 修改 server_name / 证书路径 / 后端地址 127.0.0.1:8080
sudo nginx -t && sudo systemctl reload nginx
```

证书（任选其一）：

```bash
# 方案 A：certbot
sudo certbot --nginx -d app.<域名> -d admin.<域名>

# 方案 B：云厂商证书，手动配置 ssl_certificate / ssl_certificate_key
```

验证：

```bash
curl -I https://app.<域名>            # 200，含 HSTS
curl -I http://app.<域名>             # 301 → https
curl https://app.<域名>/actuator/health
```
