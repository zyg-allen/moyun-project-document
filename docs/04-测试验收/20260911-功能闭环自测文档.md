第一部分 · 总：什么是闭环
--------------

### 闭环的五个环节

text

入口 ──→ 操作 ──→ 反馈 ──→ 沉淀 ──→ 再入口

| 环节  | 含义        | 缺失后果   |
| --- | --------- | ------ |
| 入口  | 用户能自然找到   | 功能没人用  |
| 操作  | 能顺畅完成核心动作 | 用不下去   |
| 反馈  | 立刻知道结果    | 不知道做对没 |
| 沉淀  | 结果被记录/积累  | 下次从零开始 |
| 再入口 | 有理由再来     | 用完就走   |

### 闭环的三个层级

| 层级        | 含义       | 验证方式          |
| --------- | -------- | ------------- |
| **模块内闭环** | 单个功能自闭环  | 走一遍不断链        |
| **跨模块闭环** | 模块之间互相引流 | 从 A 能到 B 再回 A |
| **数据闭环**  | 数据在模块间流转 | 后台能看到完整轨迹     |

### 为什么闭环是上线门槛

* 代码写完 ≠ 能用

* 能用 ≠ 留得住

* **留得住 = 闭环完整**
