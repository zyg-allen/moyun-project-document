
# 个人资产管理记账App需求说明书
**版本号**：V1.1  
**发布日期**：2026年9月3日  
**适用平台**：微信小程序、iOS App、Android App  
**产品核心定位**：以「资产/负债」为核心视角的轻量化个人资产管理工具，核心价值主张为「让用户用一个数字看清自己的全部身家」，彻底解决传统记账产品操作复杂、无明细记录、总数无法联动增减的普遍痛点。

## 一、产品背景与市场分析
### 1.1 市场现状
当前个人记账理财赛道存在明显供需错配，主流产品呈现两个极端：
- 传统头部记账App（随手记、挖财）功能堆砌复杂，大量使用会计专业术语，普通非财务背景用户上手门槛极高，长期留存率不足10%。
- 轻量化工具类产品仅支持基础记账功能，缺失资产负债联动能力，用户频繁反馈出现账实不符问题，最终放弃使用。

### 1.2 目标用户画像
精准覆盖22-45岁、月收入5000-50000元的上班族、自由职业者、小微企业主，这类群体有明确的资产管理需求，同时被现有产品的高门槛劝退，是当前市场的核心空白受众。

### 1.3 竞品差异化对比矩阵
| 对比维度 | 本产品 | 传统头部记账App | 轻量化记账工具 |
| --- | --- | --- | --- |
| 核心视角 | 资产负债净资产全局视角 | 日常收支流水视角 | 单一收支记录视角 |
| 操作门槛 | 零会计基础即可上手 | 需学习专业术语操作 | 仅支持基础流水记录 |
| 明细追溯能力 | 全操作留痕，总资产可穿透查明细 | 仅支持流水筛选 | 无关联明细追溯能力 |
| 联动计算能力 | 还款/转账自动同步更新两边余额 | 需手动分别修改 | 无联动逻辑，总数无法自动同步 |
| 隐私保护等级 | 全量数据加密，支持全局隐藏金额 | 基础密码保护 | 无额外隐私防护 |

## 二、核心用户痛点与闭环解决方案
### 2.1 三大核心痛点
1.  **操作复杂语义不清**：普通用户看不懂「借贷」「应付款」等专业财务术语，不知道该如何操作记账，新手用户首次使用流失率极高。
2.  **记账无明细**：用户登记资产负债后，无法追溯每一笔收支、还款的去向，长期使用后完全记不清资金变动轨迹。
3.  **总数无法联动增减**：还款操作后资产减少但负债余额没有同步更新，导致总资产、净资产数字对不上，用户最终完全不信任App的财务数据。

### 2.2 对应闭环解决方案
1.  **操作门槛优化**：全量文案改用日常用语替代专业术语，首次使用提供场景身份引导，支持自然语言一键自动生成记账记录，全局设置统一「记一笔」快捷入口，3步即可完成记账操作。
2.  **全明细追溯体系**：所有记账记录永久留存流水明细，每个资产/负债账户的详情页都展示其关联的所有操作记录，首页总资产数字支持直接穿透查看全部资产明细，每一笔资金变动都可追溯。
3.  **自动联动计算机制**：选择还款类记账时，系统自动同步扣减对应资产和负债余额，首页净资产用红绿颜色标识涨跌状态，一键生成专业资产负债表，彻底避免账实不符问题。

## 三、产品整体架构与核心功能
产品采用6大模块分层架构，底部导航设置「首页、资产、负债、记账、我的」5个Tab，用户打开App直接进入首页总览仪表盘。

### 3.1 首页总览模块
核心展示自动计算的净资产、总资产、总负债三大核心数字，同时附带本月收支、预算进度、最近20条流水，支持快速跳转记账和全量流水页，首屏即可满足用户「一眼看清全部身家」的核心需求。

### 3.2 资产模块
覆盖现金、储蓄卡、电子钱包、储值卡、投资、固定资产、债权等全类型资产账户，每个账户独立展示余额、关联全部流水明细，支持一键隐藏余额的隐私保护功能。

### 3.3 负债模块
包含信用卡、消费贷、银行贷款、个人借款等负债类型，除基础欠款金额外，额外展示还款进度、还款日和到期日提醒，每笔还款都留痕可查，负债结清后自动标记归档，不干扰在用负债统计。

### 3.4 记账模块
支持收入、支出、转账、还款、借款五种记账类型，系统自动联动更新对应资产、负债余额：
- 转账操作仅在资产账户间流转余额，总资产总数保持不变
- 还款操作同时扣减对应资产余额和负债欠款
- 借款操作同时新增对应资产余额和负债欠款
流水支持多维度筛选、修改和删除，操作后自动回退调整账户余额。

### 3.5 报表模块
提供收支趋势图、分类占比饼图、资产分布、净资产趋势、资产负债表、月度汇总等多类可视化报表，支持自定义选择任意时间范围查询，所有统计数据支持一键导出为Excel、CSV格式。

### 3.6 我的模块
承载账户管理、分类管理、预算管理与系统设置功能，支持设置月度总预算和分类独立预算，临近或超支时自动推送提醒，同时提供生物识别锁定、全局隐私模式、数据加密备份等安全功能。

## 四、边缘异常场景规则
1.  删除关联大量历史流水的资产/负债账户时，系统自动将该账户标记为停用归档，所有关联流水永久保留不删除，不影响历史报表统计。
2.  跨月修改历史记账记录后，系统自动回溯重新计算对应月份的预算、收支统计数据，同步更新所有关联报表。
3.  支持多币种记账，用户可自定义本位币，系统自动调用实时汇率接口完成跨币种资产折算，统一汇总到总资产中。
4.  负债结清后自动标记为已完成状态，单独归档展示，不再计入当前总负债统计。

## 五、新手冷启动引导规则

- 选择「有房贷用户」：自动预填房贷负债账户模板，引导用户直接录入初始欠款金额
- 选择「小微企业主」：自动新增经营资产、经营性负债独立分类
