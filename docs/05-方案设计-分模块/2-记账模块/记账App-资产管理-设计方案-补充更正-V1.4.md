# 八种记账类型 · 完整逻辑与资产联动

## 一、八种记账类型总览

| #   | 类型     | 场景           | 资金方向 | 净资产影响      |
| --- | ------ | ------------ | ---- | ---------- |
| 1   | 支出     | 消费、付费        | 出    | **减少**     |
| 2   | 收入     | 工资、经营收入      | 进    | **增加**     |
| 3   | 转账     | 账户间调拨        | 内部   | 不变         |
| 4   | 借出     | 借钱给别人/客户赊账   | 出    | 不变         |
| 5   | 收款     | 别人还我钱        | 进    | 不变         |
| 6   | 借款     | 我向别人借钱/供应商赊账 | 进    | 不变         |
| 7   | 还款     | 我还别人钱        | 出    | 不变         |
| 8   | **投资** | 买入/卖出投资品     | 出/进  | 不变（浮动盈亏另算） |

**核心区分：只有 1、2 真正改变净资产，其余 6 种都是资产/负债内部的形态转换。**

## 二、资产与负债的存放表

### 2.1 资产侧（5 类）

| 资产类别     | 存放表          | 说明            |
| -------- | ------------ | ------------- |
| **资金账户** | cash_account | 现金、微信、支付宝、银行卡 |
| **库存资产** | stock        | 商品、货物（按成本价计）  |
| **应收款**  | receivable   | 别人欠我的钱        |
| **投资资产** | investment   | 基金、股票、理财      |
| **固定资产** | fixed_asset  | 房产、车辆、设备      |

### 2.2 负债侧（2 类）

| 负债类别      | 存放表        | 说明         |
| --------- | ---------- | ---------- |
| **应付款**   | payable    | 我欠供应商/朋友的钱 |
| **内部应付款** | settlement | 我欠公账的（垫资等） |

## 三、八种类型的资金走向与表操作

### 类型 1：支出

**场景：** 买咖啡 30 元，微信支付

| 表                | 变化      |
| ---------------- | ------- |
| cash_account（微信） | **-30** |
| 支出分类表            | +1 条记录  |
| 净资产              | **-30** |

**公式：** `净资产 -= 金额`

**此消彼长：** 资金账户减少，无对应资产增加，净资产真实减少。

---

### 类型 2：收入

**场景：** 收到工资 10000 元，打入银行卡

| 表                 | 变化         |
| ----------------- | ---------- |
| cash_account（银行卡） | **+10000** |
| 收入分类表             | +1 条记录     |
| 净资产               | **+10000** |

**公式：** `净资产 += 金额`

**此消彼长：** 资金账户增加，无对应负债增加，净资产真实增加。

---

### 类型 3：转账

**场景：** 微信转 500 元到银行卡

| 表                 | 变化       |
| ----------------- | -------- |
| cash_account（微信）  | **-500** |
| cash_account（银行卡） | **+500** |
| 净资产               | **不变**   |

**公式：** `账户A -= 金额；账户B += 金额`

**此消彼长：** 资金在两个账户间流动，总资产不变。

---

### 类型 4：借出

**场景：** 借给张三 1000 元；或客户赊账拿货 500 元

| 表                | 变化              |
| ---------------- | --------------- |
| cash_account（微信） | **-1000**       |
| receivable       | **+1000**（张三欠我） |
| 净资产              | **不变**          |

**公式：** `资金账户 -= 金额；receivable += 金额`

**此消彼长：** 钱从「现金」变成「别人欠我的」，总资产不变。

**库存联动：** 客户赊账拿货时，receivable 增加，同时 stock 减少（货出去），差额是利润。

---

### 类型 5：收款

**场景：** 张三还我 1000 元；或客户结清赊账 500 元

| 表                | 变化                |
| ---------------- | ----------------- |
| cash_account（微信） | **+1000**         |
| receivable       | **-1000**（张三不再欠我） |
| debt_repayment   | +1 条核销流水          |
| 净资产              | **不变**            |

**公式：** `资金账户 += 金额；receivable -= 金额；receivable.paid_amount += 金额`

**此消彼长：** 钱从「别人欠我的」变回「现金」，总资产不变。

**特殊情况：** 对方多还 100 元利息 → 差额计入收入，净资产 +100。

---

### 类型 6：借款

**场景：** 向李四借 5000 元；或供应商赊账给我 3000 元

| 表                 | 变化              |
| ----------------- | --------------- |
| cash_account（银行卡） | **+5000**       |
| payable           | **+5000**（我欠李四） |
| 净资产               | **不变**          |

**公式：** `资金账户 += 金额；payable += 金额`

**此消彼长：** 钱从「别人借给我」变成「现金」，同时增加一笔负债，总资产不变。

**库存联动：** 供应商赊账给我时，payable 增加，同时 stock 增加（货进来）。

---

### 类型 7：还款

**场景：** 我还李四 5000 元；或结清供应商赊账 3000 元

| 表                 | 变化                |
| ----------------- | ----------------- |
| cash_account（银行卡） | **-5000**         |
| payable           | **-5000**（我不再欠李四） |
| debt_repayment    | +1 条核销流水          |
| 净资产               | **不变**            |

**公式：** `资金账户 -= 金额；payable -= 金额；payable.paid_amount += 金额`

**此消彼长：** 钱从「现金」变回「还债」，同时负债减少，总资产不变。

---

### 类型 8：投资

**场景 A：买入投资品**（基金 10000 元）

| 表                 | 变化         |
| ----------------- | ---------- |
| cash_account（银行卡） | **-10000** |
| investment        | **+10000** |
| 净资产               | **不变**     |

**公式：** `资金账户 -= 金额；investment += 金额`

**场景 B：卖出投资品**（基金涨到 12000 元）

| 表                 | 变化               |
| ----------------- | ---------------- |
| cash_account（银行卡） | **+12000**       |
| investment        | **-10000**（成本结转） |
| 收入                | **+2000**（投资收益）  |
| 净资产               | **+2000**        |

**公式：** `资金账户 += 卖出价；investment -= 成本价；收入 += 差额`

**此消彼长：** 买入时，钱变成投资品；卖出时，投资品变回钱，差额是真实盈亏。

## 四、总资产结构

```
总资产
├── 资金账户（现金、微信、支付宝、银行卡）
├── 库存资产（商品、货物，按成本价）
├── 应收款（别人欠我的）
├── 投资资产（基金、股票、理财，按市值）
└── 固定资产（房产、车辆、设备）
        ↓
   总资产 = 资金 + 库存 + 应收 + 投资 + 固定资产

总负债
├── 应付款（我欠供应商/朋友）
└── 内部应付款（我欠公账的）

   总负债 = 应付款 + 内部应付款

净资产 = 总资产 - 总负债
```

## 五、八种类型的统一公式

| 类型   | 资金账户     | 资产侧   | 负债侧   | 净资产     |
| ---- | -------- | ----- | ----- | ------- |
| 支出   | -X       | —     | —     | **-X**  |
| 收入   | +X       | —     | —     | **+X**  |
| 转账   | A-X, B+X | —     | —     | 不变      |
| 借出   | -X       | 应收 +X | —     | 不变      |
| 收款   | +X       | 应收 -X | —     | 不变      |
| 借款   | +X       | —     | 应付 +X | 不变      |
| 还款   | -X       | —     | 应付 -X | 不变      |
| 投资买入 | -X       | 投资 +X | —     | 不变      |
| 投资卖出 | +X       | 投资 -X | —     | **±差额** |

## 六、这种方式怎么样

### 优点

| 维度       | 评价                        |
| -------- | ------------------------- |
| **逻辑自洽** | 会计恒等式成立：资产 = 负债 + 所有者权益   |
| **用户易懂** | 八种类型覆盖日常场景，用户凭直觉就能选对      |
| **可追溯**  | 每笔操作都有对应表和流水，可审计          |
| **联动强**  | 记账、库存、债务、投资四个模块互相打通       |
| **扩展性好** | 未来加「工资」「分红」「报销」等，都是这八种的组合 |

### 潜在问题

| 问题           | 建议                           |
| ------------ | ---------------------------- |
| **用户选错类型**   | 前端做引导，比如「借钱给别人」→ 自动匹配「借出」    |
| **应收/应付混淆**  | 用颜色和方向区分：应收=资产（绿色），应付=负债（红色） |
| **投资盈亏计算复杂** | 买入按成本记，卖出自动算差额，避免用户手动算       |
| **转账和借出容易混** | 转账是「自己的钱换个地方」，借出是「钱给别人了」     |
| **信用赊账场景**   | 销售赊账自动建应收，采购赊账自动建应付，用户无需手动   |

### 综合评价

**这种方式是合理的，核心优势是「统一框架 + 自动联动」。**

八种类型覆盖了个人和小生意的全部资金场景，且每一种都有明确的资产/负债联动逻辑。用户不需要懂会计，只需要选对类型，系统自动处理后续的账户变动。

**最大的设计原则是：用户选类型，系统算账。** 用户不需要知道「借出」对应「应收款」，他只需要知道「我借给张三 1000 元」，系统自动处理应收款、流水、核销。

## 七、一句话总结

**八种类型：支出、收入、转账、借出、收款、借款、还款、投资。只有支出和收入改变净资产，其余六种都是资产/负债内部转换。资产侧五类：资金、库存、应收、投资、固定资产；负债侧两类：应付、内部应付。总资产 = 五类资产之和，净资产 = 总资产 - 总负债。用户选类型，系统自动联动，这就是最合理的设计。**

五、库存模块与债务的联动
------------

### 5.1 销售出库

| 支付方式 | 自动动作                      |
| ---- | ------------------------- |
| 现金   | 资金账户 +X，库存 -X             |
| 赊账   | receivable +X（客户欠我），库存 -X |

### 5.2 采购入库

| 支付方式 | 自动动作                    |
| ---- | ----------------------- |
| 现金   | 资金账户 -X，库存 +X           |
| 赊账   | payable +X（我欠供应商），库存 +X |

### 5.3 收款/还款

* 收款：核销 receivable，写 debt_repayment，更新 paid_amount 和 status

* 还款：核销 payable，写 debt_repayment，更新 paid_amount 和 status

六、三种仓库模式
--------

| 模式      | 适用     | 资金归属               |
| ------- | ------ | ------------------ |
| **个人仓** | 只有你一个人 | 完全个人记账             |
| **家庭仓** | 夫妻、家人  | 货是家里的，收入进经营账，不严格分成 |
| **合伙仓** | 朋友、合伙人 | 销售额进公账，按约定比例分成     |

**内部结算用 `settlement` 表**（垫资/还款/分红/提款）。

十一、验收标准
-------

1. 八种记账类型均可正常录入，资产/负债/净资产变动正确

2. 销售赊账自动生成应收款，采购赊账自动生成应付款

3. 收款/还款能核销对应债务，状态自动更新

4. 资产总览公式正确，个人与公账分开显示

5. 三套主题切换正常，无红绿撞色

6. 所有操作三步内完成

十二、核心原则
-------

* **克制**：不做企业级 ERP，只做散户、个体户、夫妻店真正需要的功能

* **简洁**：操作路径最短，避免复杂财务术语

* **联动**：记账与库存自然联动，不增加用户额外负担

* **可追溯**：库存流水、债务核销、操作日志完整保留

* **用户选类型，系统算账**：用户不需要懂会计，只需选对类型

十四、一句话总结
--------

**八种记账类型，两个主表（asset_account/liability_account）+ 若干子表，支出收入改净资产，其余六种是形态转换。库存和债务联动，个人和公账分开，三套主题配色优化。核心是「用户选类型，系统算账」，让散户也能看懂自己赚了多少钱。**
