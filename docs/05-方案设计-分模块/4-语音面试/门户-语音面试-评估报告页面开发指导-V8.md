## 二、整体信息架构与页面流转

```
[面试准备页 interview-prep]
   ├─ 完成设备检测
   ├─ 填写岗位与简历
   └─ 点击「开始 AI 语音面试」
          │  (携带 jobId、resumeId、difficulty 参数跳转)
          ▼
[面试过程页 interview-process]
   ├─ 左栏：面试官 + 本次考察知识点
   ├─ 中栏：面试对话（AI 提问 / 我的回答 / 评分反馈）
   ├─ 右栏：面试背景 + 面试提示
   └─ 点击「结束面试」→ 确认框 → 生成报告
          │  (跳转至 /interview/voice?id=2)
          ▼
[面试报告页 interview-report]
   ├─ 紫色 Hero 头部 + 评分卡
   ├─ 7 个 Tab：面试背景 / 概览评分 / 面试回放 /
   │           逐题分析 / 语音指标 / 改进建议 / 数据接口
   └─ 分享弹窗 + 导出简历 PDF
```

## 三、通用设计规范（三页共用，主要是和原网站的全局样式对应）

### 视觉规范

- **背景色**：`#f5f6f9`，附带两处径向渐变光晕（紫/靛），`background-attachment: fixed`
- **卡片**：白底，`1px solid #e8eaef` 边框，圆角 `16px`，极轻阴影
- **主色**：`#4f46e5` / `#7c3aed`（品牌紫）
- **状态色**：低分 `#e11d48`，中分 `#d97706`，高分 `#059669`
- **字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- **字号**：正文 `12.5–14px`，标题 `15–19px`，大分数 `56px / font-weight 900`
- **圆角**：卡片 `16px`，按钮 `10px`，标签 `99px`
- **CSS 变量**：统一使用 `:root` 定义 `--primary` / `--green` / `--red` 等

### 通用交互

- **Toast**：底部居中，带图标 + 淡入淡出，2.2 秒后消失
- **复制反馈**：`navigator.clipboard`，按钮文案变「已复制 ✓」并变绿，1.6 秒还原
- **响应式断点**：`1024px` / `960px` / `760px` / `640px` / `560px`

## 五、页面二：面试过程页 `interview-process`

### 5.1 布局结构（三栏）

```
┌───────────────────────────────────────────────────────────┐
│ 顶部悬浮栏（毛玻璃 + 底部细线）                            │
│ [🏠 首页 › 学习中心 › 模拟面试 › 面试过程]                 │
│                          [●22:27 | ●在线·等待回答]        │
│                          [🔊播报中][⏸暂停][⏹结束面试]     │
├──────────────┬──────────────────────────┬─────────────────┤
│  左栏 252px  │      中栏 自适应          │  右栏 288px     │
│              │                          │                 │
│ [面试官头像] │ [面试对话]                │ [🎯面试背景]     │
│              │  🤖 AI提问（灰底）        │  目标岗位        │
│ [🎯本次考察  │  ⭐ 高亮问题卡            │  题目难度        │
│  知识点]     │  👤 我的回答（浅红底）    │  简历锚定        │
│  ① 自我...  │  💬 评分反馈（灰底）      │                 │
│  ② 项目...  │                          │ [💡面试提示]     │
│  ...        │ [输入框 + 发送]           │  1. 智能提示    │
│             │ [⏭跳过] [📝清空] [💡提示] │  2. 逐级升级    │
│             │ [✓回答完毕]               │  3. 先自己想    │
└──────────────┴──────────────────────────┴─────────────────┘
```

### 5.2 关键元素说明

#### 顶部悬浮栏

- **面包屑**：`首页 › 学习中心 › 模拟面试 › 面试过程`，首页带 SVG 房屋图标，宽屏显示完整，窄屏隐藏深层级
- **状态胶囊**：毛玻璃白底圆角胶囊，包含计时器（绿点脉冲 + `MM:SS`）和「在线 · 等待回答」状态，中间竖线分隔
- **操作按钮组**：3 个按钮 — 播报中（紫色高亮）/ 暂停 / 结束面试（红色描边）

#### 左栏

- **面试官头像卡**：104px 圆形光环 + 蓝色渐变背景 + 姓名 + 在线状态
- **本次考察知识点**：
  - 卡片标题 + 计数胶囊「10 个」
  - 提示条：「以下为本次面试的预设考察方向...」
  - 列表项：序号 + `point`（截断至 10 字）+ 分类标签
  - 当前项用红紫渐变高亮
  - **悬停 tooltip**：右侧弹出深色卡片，显示完整 `tag + point + full 题目`

#### 中栏聊天区

- **消息类型**：
  - `msg ai .msg-bubble`（灰底）：AI 提问
  - `msg-highlight`（黄底 + 左侧橙色竖条）：高亮问题卡，含「⭐ 问题 N/M · 题源」
  - `msg user .msg-bubble`（浅红底）：我的回答
  - `feedback-bubble`（灰底）：评分反馈
- **输入区**：自适应高度文本域 + 右下角圆形发送按钮
- **操作行**：`⏭ 跳过本题 | 📝 清空文本 | 💡 智能提示 | ✓ 回答完毕`
  - 跳过本题：浅紫色描边按钮
  - 清空文本 / 智能提示：灰色 ghost 按钮
  - 回答完毕：紫渐变主按钮，靠右对齐

#### 右栏

- **面试背景卡**：目标岗位 / 题目难度 / 简历锚定 + 分隔提示
- **面试提示卡**：3 条编号提示项（不是「面试官提示」）

### 5.3 关键交互

| 交互       | 说明                                   |
| -------- | ------------------------------------ |
| 计时器      | 每秒 +1，格式 `MM:SS`                     |
| 播报中/暂停   | 点击切换文案和样式；播报中用 `.playing` 紫色高亮       |
| 结束面试     | 打开自定义确认框（⚠️ 图标 + 「继续面试」/「确定结束」）      |
| 跳过本题     | `currentIdx++`，重新渲染知识点列表             |
| 智能提示     | 3 级递进，每次提示更具体                        |
| 发送回答     | 追加用户气泡 → 1.2 秒后追加 AI 反馈（含 typing 动画） |
| Enter 发送 | 支持 `Enter` 发送，`Shift+Enter` 换行       |
| 知识点点击    | Toast 提示「第 N 个考察点：XXX」               |

### 5.4 结束面试确认框

- 遮罩 + 淡入 + 缩放动画
- 圆形警示图标（红色渐变）
- 标题：「确定结束本次面试？」
- 说明：「结束后将立即生成评估报告，本次面试不可恢复。建议回答完当前题目再结束。」
- 按钮：「继续面试」（灰边）/「确定结束」（红色渐变）
- 支持点击遮罩关闭 + ESC 关闭

### 5.5 后端接口建议

```
POST /api/v1/interviews/{id}/answer       提交回答（音频 + 文本）
GET  /api/v1/interviews/{id}/next-question 获取下一题（SSE 或轮询）
POST /api/v1/interviews/{id}/hint         获取智能提示（level 参数）
POST /api/v1/interviews/{id}/skip         跳过本题
POST /api/v1/interviews/{id}/end          结束面试，返回 reportId
```

### 6.2 Tab 详细内容

#### Tab 1：🎯 面试背景（默认选中）

- 两列卡片：
  - 左「💼 目标岗位信息摘要」：岗位名、薪资、地点、学历、面试难度、题源、时间、时长、岗位职责列表
  - 右「👤 候选人概要」：姓名、经验年限、候选人 ID、报告编号、技能标签 chips
- 全宽「简历概要」：简历自我介绍 + 面试口头自我介绍（两个灰底卡片）
- 全宽「技术概要」：按 `techGroups` 分组展示标签

#### Tab 2：📋 概览评分

- **Canvas 六维雷达图**：
  - 4 层同心网格 + 轴线
  - 数据多边形从 0 生长动画（950ms）
  - 顶点按 level 描边（high 绿 / mid 橙 / low 红）
  - 标签显示维度名 + 分数
- **维度评分明细**：名称 + 进度条 + 分数 + 点评
- **核心优势与待改进项**：双栏卡片（左绿右橙）

#### Tab 3：💬 面试回放（重点）

- **顶部控制条**：`▶ 从头播放` + 进度条 + 计数器「N / M」
- **聊天式布局**（仅 AI 提问 + 我的回答，**不要点评气泡**）：
  - AI 问题：左侧红橙渐变头像「AI」+ 灰底气泡，左上角「问题 N」
  - 我的回答：右侧浅红底气泡，右上角悬浮分数徽标（≥80 绿 / 60-79 橙 / <60 红），最右侧白色「我」标签
- **播放动画**：所有轮次先隐藏 → 逐条添加 `.on` class 淡入（间隔 650ms），进度条与计数器同步，自动滚动

#### Tab 4：🔍 逐题分析

- 筛选 chips：`全部 / 薄弱<60 / 中等60-79 / 含风险点`
- 题目卡片可展开：
  - 回答摘要（`{{}}` 渲染为高亮底纹）
  - AI 点评（`{{}}` 渲染为红色加粗）
  - 优化建议（紫底卡片）
  - 标签行（绿/橙/红三色）

#### Tab 5：🎙️ 语音指标

- 指标卡片网格：名称、数值、单位、状态色、基准值、评语
- 语速波动曲线：56 根竖条，点击播放按钮逐段点亮，时间同步推进

#### Tab 6：🚀 改进建议

- `devLead` 引导语
- `devPlan` 列表：优先级序号 + 标题 + 收益胶囊 + 当前差距 + 行动建议
  - 左侧色条按 level 区分（p1 红 / p2 橙 / p3 紫）
- 7 天补强计划表格：时间 / 训练内容 / 目标产出

#### Tab 7：🔌 数据接口

- 接口清单：`GET /api/v1/interview-reports/{reportId}`（主接口）
- JSON 响应示例（深色代码块 + 语法高亮 + 复制按钮）
- 字段说明表（标注 🤖 AI 生成字段）
- 开发提示词展示（可复制）

### 6.3 导出简历 PDF

- 点击生成独立的 A4 简历 HTML
- 内容包含：姓名、目标岗位、经验年限、候选人 ID、导出日期、个人简介、技能标签、技术栈、求职意向、面试口头自我介绍
- 样式：紫色主色调、专业排版、`@page` 设置 A4 边距
- `window.open` 打开新窗口 + 自动调用 `window.print()`
- 用户可在打印窗口选择「另存为 PDF」

### 6.4 分享报告弹窗

- 遮罩 + 淡入动画 + 右上角关闭按钮
- 内容：
  - 报告链接输入框（只读）+ 复制按钮
  - 四个分享渠道：微信 / QQ / 微博 / 复制链接
  - 二维码区域（占位图 + 文字说明）
- 复制链接使用 `navigator.clipboard`，成功后按钮变绿显示「已复制 ✓」
- 支持 `navigator.share` 原生分享
- 点击遮罩或 ESC 关闭
