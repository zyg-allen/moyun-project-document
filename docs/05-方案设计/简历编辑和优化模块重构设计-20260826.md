## 二、当前流程中的断裂点

| 断裂点            | 影响            | 严重度  |
| -------------- | ------------- | ---- |
| 模板库 → 编辑页无数据传递 | 用户不能从模板快速创建简历 | 🔴 高 |
| AI建议采纳后未联动保存   | 用户需手动保存，易遗忘   | 🟠 中 |
| 评分无岗位JD对比      | 评分仅基于内容，不够精准  | 🟠 中 |
| 评分报告不能保存       | 无法追溯历史评分      | 🟡 中 |
| 深度优化无前后对比视图    | 用户看不到变化，感知弱   | 🟡 中 |
| 无AI实时辅助编辑      | 用户需手动优化每个字段   | 🟡 中 |

## 三、新需求说明

### 3.1 核心目标

将简历模块升级为 **「AI驱动的简历工作台」** ，实现从模板套用、AI实时辅助、岗位匹配评分到深度优化对比的完整闭环。

### 3.2 新需求列表

| 序号  | 需求           | 优先级   | 说明                   |
| --- | ------------ | ----- | -------------------- |
| 1   | **模板套用数据打通** | 🔴 P0 | 点击「使用此模板」将模板数据填充到编辑页 |
| 2   | **AI实时辅助编辑** | 🔴 P0 | 编辑字段时AI提供优化建议，用户选择采纳 |
| 3   | **岗位匹配评分**   | 🔴 P0 | 基于目标岗位JD精准评分         |
| 4   | **评分报告保存**   | 🟡 P1 | 保存每次评分结果为报告          |
| 5   | **深度优化前后对比** | 🟡 P1 | 逐项展示优化前后内容，用户选择性采纳   |
| 6   | **预览微调闭环**   | 🟢 P2 | 优化后预览 → 微调 → 保存/导出   |
| 7   | **重新评分闭环**   | 🟢 P2 | 最终优化结果可重新评分，以最终结果为准  |
| 8   | **岗位信息管理**   | 🟡 P1 | 用户可创建/管理目标岗位信息       |

### 4.2 核心参考功能点

1. **模板套用**：点击模板 → 一键填充内容到编辑页
2. **AI实时辅助**：编辑时AI提供多版本建议 → 用户选择采纳
3. **岗位匹配**：输入JD → AI对比分析 → 匹配度+关键词+建议
4. **深度优化**：分析进度弹窗 → 前后对比 → 逐项采纳 → 预览微调 → 保存导出

## 五、两条核心流程

### 流程一：模板 → 编辑 → AI实时辅助 → 保存

```
模板列表 → 选择模板 → 一键套用 → 编辑页填充 → AI实时辅助 → 采纳建议 → 预览 → 保存/导出
```

### 流程二：简历评分 + 深度优化 → 对比 → 保存

```
选择简历（列表/上传） → 填写岗位JD → AI评分 → 评分报告 → 深度优化 → 前后对比 → 逐项采纳 → 微调编辑 → 保存/导出 → 可重新评分（以最终结果为准）
```

### 2.2 新增数据模型

```typescript
// ===== 岗位目标 =====
interface JobTarget {
  id: number;
  userId: number;
  position: string;           // 目标岗位名称
  company?: string;           // 目标公司（选填）
  city?: string;              // 期望城市
  jdText: string;             // 岗位描述/要求（核心输入）
  jdKeywords?: string[];      // AI提取的关键词
  isDefault?: boolean;        // 是否为默认岗位
  createdAt: string;
  updatedAt: string;
}

// ===== 岗位匹配结果 =====
interface JobMatchResult {
  id: number;
  resumeId: number;
  jobTargetId: number;
  matchScore: number;         // 综合匹配度 0-100
  grade: 'excellent' | 'good' | 'medium' | 'poor';
  matchedKeywords: string[];
  missingKeywords: string[];
  dimensions: {
    keywordMatch: { score: number; max: number; suggestions: string[] };
    experienceMatch: { score: number; max: number; suggestions: string[] };
    skillMatch: { score: number; max: number; suggestions: string[] };
    structureMatch: { score: number; max: number; suggestions: string[] };
  };
  suggestions: OptimizeSuggestion[];
  createdAt: string;
}

// ===== 优化建议 =====
interface OptimizeSuggestion {
  id: string;
  section: 'personal' | 'objective' | 'education' | 'work' | 'project' | 'skills' | 'evaluation';
  index?: number;            // 列表中的位置
  original: string;          // 原始内容
  optimized: string;         // AI优化后内容
  reason: string;            // 优化理由
  status: 'pending' | 'adopted' | 'skipped' | 'modified';
  adoptedAt?: string;
}

// ===== AI实时辅助 =====
interface AIAssistRequest {
  field: 'work_description' | 'project_description' | 'self_intro' | 'skills';
  originalText: string;
  context: {
    position: string;
    skills: string[];
    works: WorkExperience[];
    projects: Project[];
  };
  count?: number;            // 返回建议数量，默认3
}

interface AIAssistResponse {
  suggestions: {
    id: string;
    text: string;
    reason: string;
    score?: number;          // 建议质量评分
  }[];
}

// ===== 优化历史记录 =====
interface OptimizeRecord {
  id: number;
  resumeId: number;
  fromVersion: number;
  toVersion: number;
  scoreBefore: number;
  scoreAfter: number;
  matchScoreBefore: number;
  matchScoreAfter: number;
  adoptedCount: number;
  createdAt: string;
}
```

## 九、总结

### 核心价值

> **「AI驱动的简历工作台」——从模板套用、AI实时辅助、岗位匹配评分到深度优化对比，形成完整的闭环。每一步都让用户感受到「AI在帮我变得更好」，而不仅仅是「一个编辑工具」。**

### 差异化优势

| 对比维度 | 传统简历工具   | 墨韵·智库简历模块              |
| ---- | -------- | ---------------------- |
| 模板套用 | 仅填充格式    | 填充内容+AI实时辅助            |
| 评分   | 基于内容通用评分 | 基于岗位JD精准匹配             |
| 优化   | 给出建议     | 前后对比+逐项采纳              |
| 闭环   | 编辑-保存    | 模板→编辑→评分→优化→对比→保存→重新评分 |
