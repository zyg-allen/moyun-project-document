## 二、架构演进关键转折（为什么是现在的架构）

1. **v9.0 战略收缩**：砍社区化（PK 对战/圈子），聚焦内容引流 → 确立「内容先行」主线
2. **v9.5 单主干基线**：分支合并，此后单主干开发
3. **v10.x AI 面试核心化**：AI 语音面试成为技术壁垒，简历/题库围绕求职闭环
4. **v11.0-11.3 商业化基建**：支付通道/打赏分账/钱包
5. **v11.14-11.37 记账产品线**：第四端新增，产品扩展为「职业成长 + 个人财务」双场景
6. **v11.38-11.98 AI 统一网关**：scene_code 收口全部 LLM 调用 → 安全三件套 → V3 纯 Agent 面试 → 运行时开关 sys_config 化，确立 Agent-First 终局架构
7. **v12.0 统一 VIP**：端级粒度 + `@VipOnly` 注解驱动，替代三套旧 VIP
8. **v12.1-12.2.3 收口与语义化**：Mapper SQL 全量外置 XML → AI 调度层语义化、业务端直连 LLM 收编
9. **v12.3 架构评审整改**：三轮验证，20 项 P0 闭环
10. **v13.0-13.24 文档基线校正 + P1/第二批/第三批整改**：模块边界、数据库口径、事务边界与回滚口径、
    增量写 fail-closed、Per-request 场景记忆化、LLM 解析收敛、WS 一次性票据、防腐层、WS Origin 等
11. **v13.25-13.27 运营化收尾**：后台首页改版为分平台运营概览 → 后台菜单按门户前台五大主线重组
    （含题库迁学习中心、审核中心归并、监控去重、补齐 6 个无菜单入口）→ 文档治理
12. **v13.28 文档治理二期**：全量文档按「端-模块-功能-版本」重命名；归档 8 份雷同/已落地文档；
    「文档版本随修改升级」写入变更铁律
