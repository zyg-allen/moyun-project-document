简单

1. 两数之和 简单

通过率 52.3% 提交 1.2M 收藏 18.5K

给你一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

示例 1
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9，返回 [0, 1]。
示例 2
输入：nums = [3,2,4], target = 6
输出：[1,2]
示例 3
输入：nums = [3,3], target = 6
输出：[0,1]

约束条件

  • 2 <= nums.length <= 104
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109
  • 只会存在一个有效答案
数组 哈希表

解题思路

最直接的方法是使用暴力枚举，遍历数组中每一对元素，检查它们的和是否等于目标值。这种方法的时间复杂度为 O(n²)，在数组较大时效率较低。

更高效的方法是使用哈希表。我们边遍历数组边将元素存入哈希表中，对于每个元素 num，先检查 target - num 是否已存在于哈希表中。如果存在，说明我们找到了答案；如果不存在，则将当前元素及其下标存入哈希表。

由于哈希表的查找操作平均时间复杂度为 O(1)，因此该方法只需遍历数组一次，总时间复杂度为 O(n)。

代码示例

def twoSum(self, nums: List[int], target: int) -> List[int]: num_map = {} # 值 -> 下标 for i, num in enumerate(nums): complement = target - num if complement in num_map: return [num_map[complement], i] num_map[num] = i return []
复杂度分析
时间复杂度：O(n) — 只需遍历数组一次，每次哈希查找 O(1)
空间复杂度：O(n) — 最坏情况下需要存储 n-1 个元素到哈希表
