## 二、已完成（v13.26 第二轮：补齐 4 个无菜单模块 + 图标归位）

### 2.1 补齐「有页面 / 有接口 / 有权限码，但无菜单」的 4 个模块

调研发现这 4 个模块的 **视图页 + 前端 API + 后端 Controller + `@PreAuthorize` 权限码全部齐备**，
唯独 `sys_menu` 无菜单行 —— 除超管（`SysUser.isAdmin` 绕过 `sys_role_menu`）外任何角色都进不去，
且页面内按钮因权限码未下发而**全部隐藏**。已补 17 条菜单/功能权限：

| 模块 | 页面 | 后端 Controller | 权限前缀 | 归位 | 验证 |
|---|---|---|---|---|---|
| 竞赛管理 | `cms/contest/index` | `CmsContestController` | `cms:contest:*` | 门户管理/内容管理 | 页面 import `@/api/cms/contest` ✅ |
| 广告位管理 | `cms/ad/index` | `CmsAdSlotController` | `cms:ad:*` | 门户管理/内容管理 | 页面 import `@/api/cms/ad` ✅ |
| 写作提示词 | `cms/prompt/index` | `CmsWritingPromptController` | `cms:writing-prompt:*` | 门户管理/内容管理 | 页面 import `@/api/cms/prompt` ✅ |
| 导入模板配置 | `cms/importTemplate/index` | `CmsImportTemplateController` | `cms:importTemplate:*` | 系统设置/系统工具 | 页面 import `@/api/cms/importTemplate` ✅ |

> 竞赛页对应门户前台 `/contest`（前台 `ContestListPage` / `ContestDetailPage` 已上线），此前**后台完全管不了**。

### 2.2 菜单图标归位（7 条失效图标）

侧边栏渲染为 `<svg><use href="#icon-{name}"/></svg>`，图标名不存在时**静默渲染空白、无报错**，
属难以察觉的缺陷。全量比对 `sys_menu.icon` ↔ `src/assets/icons/svg/` 后修正：

`warning`→`eye`(举报管理)、`microphone`→`rate`(语音面试)、`card`→`money`(用户银行卡)、
`shield`→`eye-open`(内容安全检测)、`crown`→`star`(VIP管理)、`idcard`→`user`(用户会员卡)、
`trophy`→`star`(成就管理)。**修正后全库菜单图标零失效。**

### 2.3 环境修复（非本次代码变更，但阻塞基线验证）

`VipGrantCardDbTest` 2 例失败，根因：dev 库 `vip_user_card` 仍是**非唯一** `idx_user_platform`，
即 `increment-sql/20260927-01`（README 标注"已有库必须执行"）**从未在此库执行**。
已补执行该前置脚本 → 全量 `mvn -o test` **422 例全绿**（与项目记录的基线一致）。
本项与 v13.26 代码无关（未改动任何 vip 文件），但建议在部署清单中加"前置脚本已执行"检查。
