# 收费/订阅/会员功能下线清单（2026-10-03）

> 目的：**彻底下线一切"有偿信息服务"能力**（订阅、会员、支付、打赏、分账、提现、结算），
> 使平台以**纯免费**形态合规上线（个体工商户主体不具备 ICP 经营许可条件，
> 依《互联网信息服务管理办法》第 11 条非经营性不得从事有偿服务）。
> 日后若注册公司并取得许可，可按本文档逆向恢复（实体/表结构建议保留归档，见 §4）。
