无非就是，根据个人的收入支出以及负债，资产，流水等给自己一个财务状况报告，简单说就是， 查个人信息》拼接上下文、提示词、生成标准化格式输出》落表》返回报告》展示
标准化方案：
	查数据(流水/资产/负债/画像)
  → 组装 ledgerContext（结构化数据+规则算好的指标，作为护栏传入）
  → 网关 execute(finance_analysis, {ledgerContext, window})
      Handler 读配置模板渲染：system = config.system_prompt_template
                              user  = config.user_prompt_template 替换 {ledgerContext}{window}
                              输出约束 = config.output_schema
      LLM 生成标准 JSON：{summary, healthScore(引用规则值), risks[], suggestions[]}
  → 解析合并（规则指标为基准，LLM 文案覆盖硬编码 risk/suggest 列表）
  → 落表 ledger_ai_analysis_report → 返回
  
 管理页改提示词/输出结构，下次调用立即生效，不再发版——这才配得上你建这张表的初衷。
