一、产品背景与定位
---------

### 1.1 产品背景

当前市场上的记账 App 主要分为两类：

* **传统记账 App**（如随手记、挖财）：功能庞杂、操作复杂、术语专业，普通用户学习成本高，容易放弃

* **资产管理工具**（如记账王）：聚焦资产登记，但记账操作缺乏明细记录，总数没有联动增减，用户无法追踪每笔收支的去向

用户在访谈中反馈的典型痛点：

> “操作复杂，语义不清楚，一般不知道怎么操作”  
> “记账了没有明细，总数没有两边增减计算”

### 1.2 产品定位

**个人资产管理记账 App** 是一款以“资产/负债”为核心视角的财务管理工具，区别于传统记账 App 只记录“钱花哪去了”，本 App 的核心价值是：

> **让用户用一个数字看清自己的全部身家**

### 1.3 核心价值

| 价值主张       | 说明                        |
| ---------- | ------------------------- |
| **一页看清全部** | 首页直接展示净资产、总资产、总负债，无需切换页面  |
| **记账有明细**  | 每一笔记账都有详细的流水记录，可追溯、可联查    |
| **两边联动增减** | 资产和负债的变化实时联动，系统自动计算净资产的变动 |
| **操作简单直观** | 用自然语言记账，无需学习会计术语          |

二、目标用户
------

### 2.1 用户画像

| 维度       | 描述                          |
| -------- | --------------------------- |
| **年龄**   | 22-45 岁                     |
| **职业**   | 上班族、自由职业者、小微企业主             |
| **收入**   | 月收入 5,000-50,000 元          |

### 2.2 用户痛点

| 痛点        | 说明                         |
| --------- | -------------------------- |
| **操作复杂**  | 不知道“借贷”、“转账”等术语在 App 里怎么操作 |

| **记账无明细** | 登记了负债后不知道每月还了多少、还剩多少       |

五、核心解决“记账王”痛点方案
---------------

### 5.1 痛点一：操作复杂，语义不清

| 问题      | 解决方案                              |
| ------- | --------------------------------- |
| 专业术语太多  | 所有文案使用用户能理解的日常用语，如用“还房贷”代替“负债偿还”  |
| 不知道怎么操作 | 提供“场景引导”，首次使用让用户选择身份（上班族/有房贷/学生等） |
| 记账流程复杂  | 支持自然语言记账，输入“今天买咖啡35块”自动生成记录       |
| 入口太多    | 统一入口“记一笔”按钮，从哪都能快速记账              |

### 5.2 痛点二：记账没有明细

| 问题       | 解决方案                   |
| -------- | ---------------------- |
| 只有总数没有流水 | 每一笔记录都保存在“流水明细”中，可按日查看 |
| 看不到每笔变化  | 每个账户/负债的详情页都展示其关联的所有流水 |
| 不知道钱去了哪  | 点击总资产的数字，直接穿透查看所有资产明细  |

### 5.3 痛点三：总数没有两边增减计算

| 问题           | 解决方案                      |
| ------------ | ------------------------- |
| 还了房贷资产减了负债没减 | 选择“还款”类型记账时，系统自动同时减少资产和负债 |
| 净资产变化不直观     | 首页“净资产”字段用颜色标识变化（绿色涨/红色跌） |
| 财务结构看不清      | 提供“资产负债表”一键查看全部资产和负债结构    |

十二、总结
-----

本产品定位为 **“个人资产管理记账工具”** ，核心理念是 **让用户一个数字看清全部身家**。

**三大核心价值**：

1. **一页看清**：首页直接展示净资产、总资产、总负债

2. **记账有明细**：每笔记录可追溯、可穿透查询

3. **联动增减**：资产和负债变化实时联动，系统自动计算

**与记账王的差异**：

| 维度   | 记账王     | 本产品                  |
| ---- | ------- | -------------------- |
| 操作门槛 | 高（专业术语） | 低（自然语言 + 场景引导）       |
| 记账明细 | 无       | 每条流水可追溯              |
| 联动增减 | 无       | 自动联动计算               |
| 首页总览 | 简单      | 净资产 + 总资产 + 总负债 + 趋势 |
