## 维护规则

1. **每次修改都要登记 devlog**（版本 + 类目 + 简介），不允许改了不记或事后补记。
2. **大改动同步文档**：接口契约 / 配置键 / 表结构 / 状态机 / 外部通道行为 / 菜单权限 → 同步 README、部署指南、开发规范、方案文档（四同步）。
3. **文档只写可验证行为**；无法从代码/devlog 判断的列为待确认项，不擅自断言。
4. **严重滞后的文档直接删除**（不再增补修订），保持文档与代码同向演进；删除前归档到 `.archive/`。
5. **文档版本随修改升级**（v13.28 起）：文件名统一「端-模块-功能-版本」；内容有实质修改时必须同步升版本号
   （文件名与文内版本标注一起改）并在 devlog 登记；雷同/同一修改方向的文档只保留最新主干版本，其余归档。
