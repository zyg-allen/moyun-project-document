# 面试空间 & 简历工具实施计划

## 一、背景与现状评审

### 1.1 数据库层严重问题
- 4 张表完全缺失 CREATE 脚本：`portal_interview_company`、`portal_interview_comment`、`portal_interview_comment_like`、`portal_interview_question_company`
- `portal_interview_submission` 表缺 `content/answer_type/is_success/note` 字段
- `portal_interview_experience` 表缺 `summary/cover_image/is_top` 字段
- `portal_interview_resume_template` 表缺 `file_type/file_size/is_premium/usage_guide/tags` 字段
- `21_submission_featured.sql` 第 7 行 `AFTER \`note\`` 引用了原表不存在的列

### 1.2 被清理的 9 个接口（Service 实现全部保留）
- `getMyBookmarkList` → Service: `selectBookmarkPage`（已实现）
- `adoptSubmission` → Service: `adoptSubmission`（已实现）
- `publishExperience` → Service: `insertExperience`（已实现）
- `updateExperience` → Service: `updateExperience`（已实现）
- `deleteExperience` → Service: `deleteExperienceById`（已实现）
- `deleteComment` → Service: `deleteCommentById`（已实现）
- `getResumeTemplateDetail` → Service: `selectResumeTemplateById`（已实现）
- `getCompanyList` → Service: `selectCompanyList`（已实现）
- `getCompanyDetail` → Service: `selectCompanyById`（已实现）

### 1.3 简历工具闭环缺失
- 在线编辑器：无（降级为结构化表单录入）
- PDF 导出：无（用 Flying Saucer）
- 优化建议：无（降级为规则评分）

## 三、关键决策
- 答题评测：先做"答案对比+关键词匹配"轻量方案
- 简历编辑器：结构化表单 + 固定模板渲染（不做自由编辑器）
- 简历导出：Flying Saucer（HTML→PDF）
- 简历优化：规则评分（不做 AI 建议）
- 面经发布：复用现有 QuillEditor
