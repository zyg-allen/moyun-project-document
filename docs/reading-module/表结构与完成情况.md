## 一、表结构总览

读书空间共 **17 张表**，按功能域可分 6 组：

| 功能域 | 表名 | 用途 | 来源脚本 |
|--------|------|------|----------|
| 书籍核心 | `portal_book` | 书籍主表（元数据 + 商业化 + 连载体系） | 07 + 16 + 42 |
| 书籍核心 | `portal_book_chapter` | 章节正文表（LONGTEXT，支持 Markdown） | 42 |
| 书籍核心 | `portal_book_chapter_view` | 章节浏览记录（含 IP、阅读时长） | 42 |
| 书单 | `portal_book_list` | 书单表（合集） | 07 + 16 |
| 书单 | `portal_book_list_item` | 书单-书籍关联（多对多） | 07 |
| 书单 | `portal_book_list_like` | 书单点赞 | 07 |
| 书单 | `portal_book_list_bookmark` | 书单收藏 | 22 |
| 金句 | `portal_book_quote` | 金句摘录 | 07 + 16 + 42 |
| 金句 | `portal_book_quote_like` | 金句点赞 | 07 |
| 用户行为 | `portal_reading_progress` | 阅读进度（章节级） | 07 + 42 |
| 用户行为 | `portal_bookshelf` | 个人书架（收藏书籍） | 44 |
| 用户行为 | `portal_reading_preference` | 阅读器偏好（字号/主题等） | 44 |
| 运营 | `portal_book_recommend` | 推荐位（5 种位置） | 46 |
| 共读活动 | `portal_book_club_activity` | 共读活动主表 | 07 |
| 共读活动 | `portal_book_club_participant` | 共读参与 | 07 |
| 共读活动 | `portal_book_club_record` | 共读打卡记录 | 07 |
| 共读活动 | `portal_book_club_record_like` | 打卡点赞 | 07 |

> ⚠️ 命名易混点：`portal_bookmark`（无 book_list，03 脚本）是**文章收藏表**，不属于读书空间。

## 二、核心表字段与关联关系

### 2.1 portal_book（书籍主表）

```
id              BIGINT       PK
title           VARCHAR(500) NOT NULL     书名
author          VARCHAR(200) NOT NULL     作者
cover           VARCHAR(500)              封面URL
description     TEXT                       简介
isbn            VARCHAR(50)               ISBN
publisher       VARCHAR(200)              出版社
publish_date    DATE                       出版日期
page_count      INT          DEFAULT 0    页数
category_id     BIGINT                    → portal_category.id
tags            VARCHAR(500)              标签，逗号分隔
rating          DECIMAL(3,2) DEFAULT 0.00 评分
reading_count   BIGINT       DEFAULT 0    阅读人数
status          VARCHAR(20)  DEFAULT 'active' 状态

# 16 号脚本扩展：商业化预留
access_level    VARCHAR(20)  DEFAULT 'free'    访问级别 free/vip/preview
preview_ratio   INT          DEFAULT 30          免费试读比例 0-100
price           DECIMAL(10,2) DEFAULT 0.00      书籍单价
is_featured     TINYINT(1)   DEFAULT 0          是否精选
is_recommended  TINYINT(1)   DEFAULT 0          是否推荐
summary         TEXT                             简介（纯文本）
author_bio      TEXT                             作者简介

# 42 号脚本扩展：网文连载体系
type            VARCHAR(20)  DEFAULT 'published' 类型 published/novel/longform
serial_status   VARCHAR(20)  DEFAULT 'completed' 连载状态 ongoing/completed/hiatus
word_count      BIGINT       DEFAULT 0           总字数
chapter_count   INT          DEFAULT 0           总章节数
latest_chapter_id    BIGINT                      → portal_book_chapter.id（追更展示）
latest_chapter_title VARCHAR(500)                最新章节标题
last_update_time    DATETIME                    最后更新时间
is_finished    TINYINT(1)   DEFAULT 1           是否完结（冗余字段）
```

### 2.2 portal_book_chapter（章节正文表）

```
id              BIGINT       PK
book_id         BIGINT       NOT NULL          → portal_book.id
title           VARCHAR(500) NOT NULL          章节标题
content         LONGTEXT                       章节正文（HTML，上限 4GB）
content_markdown TEXT                          Markdown 原始内容
editor_mode     VARCHAR(20)  DEFAULT 'richtext' richtext/markdown
word_count      INT          DEFAULT 0          字数统计
chapter_no      INT          NOT NULL           章节序号（从 1 开始）
volume_id       BIGINT                          分卷ID（预留字段）
is_free         TINYINT(1)   DEFAULT 1          是否免费（1=免费，0=VIP章节）
price           DECIMAL(10,2) DEFAULT 0.00       章节单价（VIP 章节购买）
is_published    TINYINT(1)   DEFAULT 0          是否已发布（0=草稿，1=已发布）
publish_time    DATETIME                        发布时间（支持定时发布）
view_count      BIGINT       DEFAULT 0          章节浏览量

UNIQUE KEY uk_book_chapter_no (book_id, chapter_no)
```

```

UNIQUE KEY uk_user_book (user_id, book_id)
```

### 2.6 portal_book_recommend（推荐位表）

```
id          BIGINT       PK
book_id     BIGINT       NOT NULL               → portal_book.id
position    VARCHAR(50)  NOT NULL               推荐位置（5种）
sort        INT          DEFAULT 0              排序（越小越靠前）
start_time  DATETIME                            开始时间（NULL=立即生效）
end_time    DATETIME                            结束时间（NULL=长期有效）
is_active   TINYINT(1)   DEFAULT 1              是否生效
remark      VARCHAR(500)                        运营备注

# 5 种推荐位
# home_banner(首页轮播) / home_hot(首页热门)
# category_top(分类顶推) / limit_free(限免专区) / discover_banner(发现页轮播)
UNIQUE KEY uk_book_position (book_id, position)
```

## 五、后续开发拓展的内容（缺口清单）

按优先级排列：

### 🔴 高优先级（核心功能缺失）

#### 5.1 书单-书籍关系管理（关系链断裂）
- **现状**：`PortalBookListAdminController` 注释声称关系维护已迁移至 `PortalBookListRelationController`，但该 Controller **实际不存在**。后台只能改 `bookCount` 数字字段，无法真正维护书单内书籍列表。
- **影响**：书单功能形同虚设，书单详情页 `selectBookListItems` 查不到数据或数据不完整。
- **待开发**：
  - 后端：`PortalBookListRelationController`（添加书 / 移除书 / 调整排序 / 查询书单内书籍）
  - 后端：对应 Service + Mapper
  - 前端后台：`bookList/index.vue` 增加"管理书籍"弹窗（穿梭框或拖拽列表）

#### 5.2 共读活动模块（完全未实现）
- **现状**：4 张表（`portal_book_club_activity` / `participant` / `record` / `record_like`）已建好，但**无 Controller、无页面、无入口**。
- **待开发**：
  - 后端：`PortalBookClubController`（活动 CRUD + 报名 + 打卡 + 点赞）
  - 后端：`PortalBookClubAdminController`（后台活动管理）
  - 前端后台：`views/portal/bookClub/` 活动管理页
  - 前端前台：`/reading/club` 活动列表页 + `/reading/club/:id` 活动详情页 + 打卡页
  - 菜单 SQL：新增共读活动菜单

### 🟡 中优先级（增强体验）

#### 5.3 金句 / 书单点赞
- **现状**：后端 `likeQuote` / `likeBookList` 已作为死接口删除，无独立 Like Controller；前台无点赞按钮。表 `portal_book_quote_like` / `portal_book_list_like` 已建好但闲置。
- **待开发**：
  - 后端：`PortalLikeController` 统一点赞接口（quote / bookList / clubRecord 复用）
  - 前端：BookDetailPage 金句卡片加点赞按钮、BookListDetailPage 加点赞按钮
  - 触发成长事件（点赞数 +1）

#### 5.4 金句独立列表页
- **现状**：前台无 `/reading/quotes` 路由，金句仅在首页和书籍详情页以区块形式展示。
- **待开发**：
  - 前端：`pages/reading/QuotesPage.vue` 金句瀑布流列表
  - 路由：`/reading/quotes`
  - ReadingPage 金句区块"查看更多"按钮跳转

#### 5.5 VIP 章节付费校验
- **现状**：表字段（`is_free` / `price` / `access_level`）已就绪，ChapterReaderPage 已有 VIP 标记 UI，但后端 `getChapterDetail` 注释明确"VIP 校验第四阶段实现"，当前返回完整正文。
- **待开发**：
  - 后端：`getChapterDetail` 根据 `is_free` + 用户 VIP 状态判断，VIP 章节返回 `preview_ratio` 比例正文 + 购买引导
  - 后端：章节购买接口 + 订单表
  - 前端：付费墙 UI + 购买按钮

### 🟢 低优先级（优化体验）

#### 5.6 推荐位拖拽排序
- **现状**：后端 `/portal/admin/bookRecommend/sort` 批量排序接口已就绪，后台 Vue 页面未对接拖拽 UI。
- **待开发**：`bookRecommend/index.vue` 引入 `vuedraggable` 实现拖拽排序。

#### 5.7 书架自定义排序
- **现状**：`portal_bookshelf.sort` 字段已预留，前台 MyBookshelfPage 仅有 latest/recent 两种排序，无拖拽自定义排序。
- **待开发**：MyBookshelfPage 引入拖拽组件，调用批量更新排序接口。

#### 5.8 章节分卷管理
- **现状**：`portal_book_chapter.volume_id` 字段预留，但**无分卷表**（`portal_book_volume`），无法实现分卷。
- **待开发**：建 `portal_book_volume` 表（id / book_id / name / sort），章节管理页支持分卷。

#### 5.9 章节自动阅读
- **现状**：ChapterReaderPage 无自动滚动功能。
- **待开发**：增加"自动阅读"按钮，可调速滚动。

#### 5.10 清理陈旧注释
- **现状**：`PortalBookListAdminController.java` 类注释提到的 `PortalBookListRelationController` 不存在，属于误导性内容。
- **待开发**：要么补齐 Controller，要么清理注释。
