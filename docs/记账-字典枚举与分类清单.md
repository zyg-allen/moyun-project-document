# 记账模块 · 字典枚举与分类清单（方案A落地）

> 本文档记录记账模块的枚举、字典树结构、分类规划，供字典管理（树形）任务对接与后续开发使用。

---

## 一、枚举（参与计算，代码层面，减少硬编码）

已落地为 Java 枚举：`moyun-server/.../ledger/domain/enums/`

| 枚举 | 取值 | 说明 |
|---|---|---|
| `AccountType` | fund资金账户 / receivable应收款 / investment投资 / fixed固定资产 | 资产账户类型（第二层） |
| `LiabilityType` | debt普通负债 / credit赊账应付 | 负债账户类型（第二层） |
| `SettleStatus` | pending未结 / partial部分结 / settled已结清 | 应收/应付结算状态 |
| `RiskLevel` | normal正常 / attention关注 / bad_debt坏账 | 账户风险标记（打标） |

另有记账行为类型（流水 `type` 字段，8 种）：
`income收入 / expense支出 / transfer转账 / lend借出 / collect收款 / borrow借入 / repayment还款 / adjust校准`

---

## 二、账户三层关系

```
第一层 大类        → 资产 / 负债
第二层 账户类型     → 资产：资金账户(流动资产)/应收款(借出)/投资/固定资产(折合)
                     负债：普通负债(借款/信用卡/车贷房贷)/赊账应付
第三层 具体账户     → 用户命名，存表（"微信"、"张三（借款）"、"招商信用卡"）
```

- 前两层 = 字典 + 枚举；第三层 = `ledger_asset_account` / `ledger_liability_account` 每行。
- 应收/应付不再独立成表，统一为「账户」，`account_type` 字段区分。

## 三、字典树（对接字典管理任务）

### 字典类型（建议拆两个）

| 字典类型 | 树结构 |
|---|---|
| `asset_category`（资产分类） | 资产 > {资金账户, 应收款, 投资, 固定资产} |
| `liability_category`（负债分类） | 负债 > {普通负债, 赊账应付} |

### 记账分类（标签式，统计用）

| 行为类型 | 大类（系统预设） | 细类示例 |
|---|---|---|
| 收入 income | 工资、奖金报酬、投资收益、卖东西、投稿 | 可加细类 |
| 支出 expense | 交通、住院、房租、购物、人情往来、宠物 | 交通→地铁/家用车/保养；购物→拼多多/淘宝/京东 |
| 转账/借出/收款/借入/还款/校准 | 行为类，无分类 | — |

- 大类可挂细类（二级），也可直接挂大类；统计按分类聚合（系统兜底保证每笔流水都能统计到）。
- 系统预设公共分类，用户可自定义（基于行为类型之下）。

## 四、数据表（方案A最终）

| 表 | 承载 |
|---|---|
| `ledger_asset_account` | 资产账户（fund/receivable/investment/fixed），含 name/description/balance/total/paid/settle_status/due_date/risk_level |
| `ledger_liability_account` | 负债账户（debt/credit），含 name/description/balance/total/paid/settle_status/分期字段/risk_level |
| `ledger_transaction` | 记账流水（8 种行为） |
| `ledger_stock` 等库存表 | 库存模块 |
| ~~ledger_obligation~~ | **已删除**（应收/应付并入账户表） |
| ~~ledger_debt_repayment~~ | **已删除**（核销=记流水+更新账户） |

---

## 五、核销逻辑（简化后）

- 收款 = 记一笔 `collect` 流水 + `UPDATE ledger_asset_account`（资金+，应收 paid_amount+）
- 还款 = 记一笔 `repayment` 流水 + `UPDATE ledger_liability_account`（资金-，应付 paid_amount+）
- 分期：定时任务每期记一笔流水，加减账户总数即可。
- 风险：账户表 `risk_level` 字段打标。
