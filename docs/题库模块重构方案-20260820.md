# 题库模块重构方案

> 基于现有代码 + `20260820题库模块重构考虑.md` + Coze 原型页面，制定分阶段落地方案。
> 目标：统一题库数据模型，支持选择题/编程题在线练习，同时兼容现有面试题库浏览。

## 一、现状梳理

### 1.1 数据库现状（已具备）
| 表 | 说明 | 状态 |
|---|---|---|
| `portal_interview_question` | 题目主表 | 已有 `question_type`（algorithm/bagwen/system_design/project/hr） |
| `portal_interview_question_test_case` | 编程题测试用例 | 已存在，可直接复用 |
| `portal_interview_question_company` | 题目公司关联 | 已存在 |
| `portal_interview_question_like` | 题目点赞 | 已存在 |

### 1.2 后端 API 现状
- `GET /portal/interview/question/list` — 已支持 `questionType` 筛选
- `GET /portal/interview/question/{id}` — 题目详情
- `GET /portal/interview/category/list` — 分类列表

### 1.3 前端现状
- `/interview/questions` → `QuestionListPage.vue`（完整题库列表，支持筛选）✅
- `/learn/practice/choice` → **404 缺失** ❌
- `/learn/practice/coding` → **404 缺失** ❌

### 1.4 核心矛盾
现有 `questionType`（algorithm/bagwen/system_design/project/hr）是"**题目内容分类**"维度；
重构想要的"选择题/编程题/面试题展示"是"**练习模式**"维度。两者正交：
- algorithm 算法题 → 练习模式可以是编程题
- bagwen 八股题 → 练习模式可以是选择题 或 展示题
- 一道选择题 → 内容可以是八股/HR/项目

## 二、重构方案：新增 practice_mode 维度（不改 questionType）

### 2.1 数据模型扩展
```sql
ALTER TABLE portal_interview_question
  ADD COLUMN practice_mode VARCHAR(20) DEFAULT 'reading'
    COMMENT '练习模式：reading=展示阅读/choice=选择题/coding=编程题',
  ADD COLUMN options JSON DEFAULT NULL
    COMMENT '选择题选项，JSON数组：[{label:"A",text:"...",is_correct:false}]',
  ADD COLUMN correct_answer VARCHAR(50) DEFAULT NULL
    COMMENT '正确答案（选择题：选项label如B；编程题：null，靠测试用例判定）',
  ADD COLUMN analysis TEXT DEFAULT NULL
    COMMENT '题目解析（做题后展示，区别于 referenceAnswer 参考答案）',
  ADD COLUMN knowledge_tags VARCHAR(500) DEFAULT NULL
    COMMENT '知识点标签，逗号分隔（用于错题本/学习路径聚类）';
```

### 2.2 练习模式与现有 questionType 的映射关系
| practice_mode | 适用 questionType | 作答方式 |
|---|---|---|
| `reading` | bagwen, system_design, project, hr | 展示阅读（看题+答案） |
| `choice` | bagwen, hr | 选择选项 → 判分 |
| `coding` | algorithm | 写代码 → 测试用例判定 |

### 2.3 前台路由规划
| 路由 | 页面 | 说明 |
|---|---|---|
| `/interview/questions` | 面试题库浏览（reading） | 现有，看题+答案 |
| `/learn/practice/choice` | 选择题列表 | 新增 |
| `/learn/practice/choice/:id` | 选择题做题页 | 新增（阶段2） |
| `/learn/practice/coding` | 编程题列表 | 新增 |
| `/learn/practice/coding/:id` | 编程题做题页 | 新增（阶段2） |
